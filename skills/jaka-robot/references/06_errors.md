# 事件码与故障诊断

来源：[事件码及含义](https://www.jaka.com/docs/guide/V3/errinfo.html)、[TCP/IP 错误码说明](https://www.jaka.com/docs/guide/V3/tcpip.html)。

官方事件表很大，并随版本扩展。收到代码时在官方页面按完整十六进制值搜索；不要只凭中文短语猜原因，也不要把信息事件当故障。

## 先分层

1. **通讯层**：连接、超时、拆包/粘包、gRPC/TCP 通道、网络状态。
2. **接口层**：返回码、参数范围、权限/控制源、模式、索引。
3. **程序层**：脚本行号、程序状态、变量、文件或 AddOn。
4. **运动层**：未上电/使能、不可达、软硬限位、奇异点、速度/加速度、碰撞/保护性停止。
5. **硬件层**：CAN、驱动器、编码器、电源、温度、TIO、扩展 IO、力传感器。

## 诊断输入

收集完整事件码和时间、机器人型号/序列、控制器与 SDK 版本、接口类型、控制源和模式、最近一次成功命令、失败命令及参数、上电/使能/急停/保护停止、`inpos`/运动/程序状态、当前关节与 TCP、负载/TCP/用户坐标系、相关 IO/总线状态和控制器日志。

## 常见类别示例

- `0x000350`：当前不在 Servo 模式；`0x000351`：Servo 模式中不能设置滤波器。
- `0x000400` / `0x000401`：IO 索引或类型超范围。
- `0x000550`：运动学逆解失败。
- `0x0F0001` / `0x0F0002`：本体未上电 / 未使能。
- `0x0F0017`：运动目标不可达；`0x0F0018`：奇异点保护性停止；`0x0F0034`：检测到碰撞。
- `0xE03E8` 起的一组代码与 AddOn 数量、服务和配置异常相关。
- `0x10F....` 大量代码是状态变化或功能 IO 事件，需要结合含义判断，不一定是故障。

## 处理原则

先停止继续下发命令并保护现场，再按官方“原因/解决措施”逐条验证。参数、模式、控制权或点位问题修正后低速单步复现；电源、驱动、编码器、安全 IO、温度或重复硬件故障不通过软件强行清除，保留日志并联系 JAKA 技术支持。
