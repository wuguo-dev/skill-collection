# ROS 2 / MoveIt 2

来源：[JAKA ROS 2 说明手册](https://www.jaka.com/docs/guide/V3/ROS/ROS2.html)，官方仓库：[JakaCobot/jaka_ros2](https://github.com/JakaCobot/jaka_ros2)。

## 已验证环境

- Ubuntu 22.04 x86_64 + ROS 2 Humble。
- 推荐 Gazebo Ignition Fortress；Gazebo Classic 虽测试可用，但官方不推荐用于 Humble。
- 推荐至少 8GB RAM（16GB 更适合 MoveIt 2/RViz）和 20GB 可用空间。

官方文档列出的模型覆盖多种 Zu、Pro、A、C 和 MiniCobo 机型；启动时必须使用仓库实际存在的 `<robot_model>` 标识，不从产品营销名猜包名。

## 包与入口

- `jaka_driver`：连接控制器，提供运动、运动学、状态等服务/节点。
- `jaka_planner`：MoveIt 2 服务器、动作与规划执行。
- `jaka_<robot_model>_moveit_config`：各机型 RViz/Gazebo 配置。

```bash
git clone https://github.com/JakaCobot/jaka_ros2.git
cd jaka_ros2
colcon build --symlink-install
source install/setup.bash
```

真实驱动：

```bash
ros2 launch jaka_driver robot_start.launch.py ip:=<robot_ip>
```

MoveIt 2 真实机服务器与 RViz：

```bash
ros2 launch jaka_planner moveit_server.launch.py robot_ip:=<robot_ip> robot_model:=<robot_model>
ros2 launch jaka_<robot_model>_moveit_config demo.launch.py
```

`jaka_driver` 服务端与 `jaka_planner` MoveIt 2 服务端不能同时运行。切换前停止现有进程并确认端口/控制权已释放。

## 单位与执行

- 官方服务示例的关节目标为 rad。
- 笛卡尔目标的 XYZ 为 mm，RPY 为 rad。
- 服务消息字段、速度/加速度单位以当前 `jaka_msgs` 接口定义为准；用 `ros2 interface show` 核对。
- 真实机器人上先在 RViz 点击 Plan 并检查轨迹，再点击 Execute；首次测试不要直接 Plan & Execute。

## 真实机安全清单

清空工作区并保持急停可达；在 JAKA App 配置安全区、关节限制、正确负载/质心和 TCP；先低速验证。轨迹需要同时检查碰撞、奇异点、关节范围和工具偏移。网络中断或规划器异常时停止继续发目标，并在控制器侧确认真实状态。
