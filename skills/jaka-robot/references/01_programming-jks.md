# 图形化编程与 JKS

来源：[指令介绍](https://www.jaka.com/docs/guide/V3/cmdhelp.html)、[JAKA 编程脚本](https://www.jaka.com/docs/guide/V3/jks.html)。

## 图形化编程路由

官方指令覆盖运动（MoveJ/MoveL/圆弧/MoveZ/轨迹记录/托盘）、IO、等待/循环/判断/多线程、位姿与运动学、字符串、Socket、Modbus、子程序、变量和力控。设计任务树时把初始化、坐标与负载设置、主流程、异常/停止处理分层；运动点位与 IO 联锁保持可追溯。

圆弧过渡/混合会牺牲精确到点。工艺点、抓放点或安全检查点使用 `tol=0`；只有确认不会越过联锁或碰撞边界时才启用正的容差。

## JKS 语言约束

- 标识符不区分大小写，只能使用字母、数字和下划线，首字符不能是数字，不能占用关键字。
- 仅支持 `#` 单行注释和单行语句；不要把一条语句拆行或一行写多条语句。
- 标量不区分布尔、整数和浮点，`false=0`、`true=1`。
- 数组只支持标量，不支持字符串数组或嵌套数组；访问支持负索引和切片，越界的单元素访问会终止程序。
- 关节位置/空间位姿均为六元素数组；长度为 mm，角度为 degree。
- 普通程序变量在程序结束后释放；持久值使用 `sysvar[5500]` 至 `sysvar[5599]`，共 100 个。

## 运动语义

```jks
target = [663.5, 8.16, 206.95, 180, 0, 0]
movl(target, 0, 100, 200, 0)
```

- `movl(var_pos, rel_flag, vel, acc, tol, ...)`：笛卡尔直线，速度 mm/s、加速度 mm/s²。
- `movj(var_pos, rel_flag, vel, acc, tol, ...)`：关节运动，速度 degree/s、加速度 degree/s²。
- `movl` 的 `rel_flag` 为 0 时是绝对位姿，1 为当前用户坐标系增量，2 为当前工具坐标系增量；`movj` 的 1 为关节增量。
- `tol=0` 精确到点；正值允许与后续段混合。
- 可选终止条件按 `[di_type, di_index, di_state]` 表达；`di_type` 需按 Basic/TIO/扩展 IO/Modbus/PROFINET/EtherNet-IP 的官方枚举核对。
- 运动前设置并核对当前 TCP、用户坐标系、负载与质心；相对运动必须明确参考坐标系。

## 线程、通讯与调试

JKS 提供线程创建/等待/销毁和临界区。共享变量或 IO 状态读写用临界区保护；循环包含可观察的退出条件或适当等待，避免占满控制器执行时间。

Socket 支持打开、关闭、发送和多种接收方式。网络读取设置超时并验证长度/格式；不要让无限阻塞的通讯掩盖停止请求。用 `log_message`、系统时钟和分阶段状态变量记录执行路径。
