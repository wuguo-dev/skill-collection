# 功能 IO 与工业通讯

来源：[功能 IO](https://www.jaka.com/docs/guide/V3/funcIO.html)、[JAKA 通讯使用手册](https://www.jaka.com/docs/guide/V3/bus.html)、[Modbus 地址表](https://www.jaka.com/docs/guide/V3/modbus.html)。

## 功能 IO

- 24V 系统按 IEC 61131-1：0–11V 为低电平，15–24V 为高电平，中间区间不要作为稳定逻辑值。
- 启动、暂停、继续、停止、上/下电、上/下使能、回初始位置、清除故障、进/退拖拽等功能 DI 多为上升沿；一级/二级倍率和防护停止为低电平语义。
- 边沿触发前后的稳定电平建议各保持至少 500ms，降低网络/扫描波动导致的漏触发。
- 二级倍率必须小于一级倍率，在 App 的程序倍率配置中设置。
- 功能 DO 可映射空闲、程序暂停/运行、错误、上电、使能、运动/静止、急停、防护停止、初始位置、拖拽、碰撞和倍率状态。

PLC 时序使用握手而不是单脉冲猜测：PLC 置请求 → 机器人功能 DI/寄存器接收 → 机器人状态 DO/寄存器确认 → PLC 撤销请求 → 机器人清除确认。为每个阶段设置超时和报警。

## 协议选择

| 需求 | 优先考虑 |
|---|---|
| 标准 PLC 周期 IO、设备描述文件集成 | PROFINET 或 EtherNet/IP |
| 通用寄存器/线圈、TCP 或串口设备 | Modbus TCP / RTU |
| 自定义上位机控制与状态 | SDK gRPC 或 10000/10001 TCP/IP |
| 机器人内脚本对设备收发 | JKS Socket / Modbus 指令 |

## 部署检查

1. 让 PLC、上位机和控制柜处于同一网段并互相可达；避免 IP 冲突。
2. 官方建议通讯使用控制柜底部网口；JAKA App 使用面板网口或 Wi-Fi，减少流量互相影响。底部网口必须处于激活状态。
3. PROFINET 导入匹配的 GSDML；EtherNet/IP 导入匹配的 EDS。
4. 控制器 1.7.2_9_rc 起，CabV2.1 与 MiniCab 的 EDS 不兼容，必须按机柜选择。
5. 按实际控制器版本打开 Modbus 地址表的 1.5/1.6/1.7 分支，不跨版本抄地址。
6. 逐项核对数据方向（Robot→PLC / PLC→Robot）、偏移、长度、位宽、符号、字节序和缩放比例。
7. 先用单个心跳和一个测试寄存器验证，再扩展到运动许可与工艺数据。

安全停止、急停和防护功能应按现场安全设计和机器人安全手册接线，不用普通通讯位替代安全回路。
