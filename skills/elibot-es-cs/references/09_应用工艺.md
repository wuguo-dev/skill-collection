# 09 应用工艺（码垛 / 焊接 / 力控 / 涂胶 / 传送带 / 视觉 / CNC）

来源：官方「应用工艺及案例」https://docs.elibot.cn/cs/1b89f

## 码垛工艺包
- 入口：任务-复合-码垛。设置：名称、坐标系（基座/自定义）、工件高度、工件计数器、码垛前/后操作。
- **排样类型**：直线（两点）、矩阵（四点，顺时针/逆时针环形示教，**不可交叉**；列数=1-2 点间工件数，行数=2-3 点间工件数）、自定义（不规则，可增删工件节点；直线/矩阵的工件节点不可删除）。
- **层**：添加层设置层数与每层排样类型；**隔离层**（隔离器高度、参考摆放位置 IsolatorPoint、拾取隔离器/Approach_isolator/Isolator_action/工具动作/Exit_isolator）。
- **每个工件处**：参照点（默认第一层第一个工件）+ 生成移动（ApproachPoint 接近点、ToolActionPoint 工具动作点=默认参照点、工具动作、ExitPoint 离开点）。
- 内置变量：pallet_lct=当前层码垛个数、pallet_lno=当前层数、pallet_sep=隔离器是否使用、pallet_tct=总码垛个数、referencePoint=参考点坐标。
- **搭配视觉偏移**：
  - 方法一：偏移**用户坐标系**（只能 X/Y，不能 RZ）——建用户坐标系（英文命名）→ 码垛指令选该坐标系 → `pose_trans` 按偏移值偏移坐标系，码垛点随坐标系移动。
  - 方法二：脚本偏移目标点——码垛指令会**临时生成用户坐标系**，须**新插入 movel**，把点位转 base+补偿值再转回临时用户坐标系下运动（不能直接把偏移点位放在码垛自动生成的运动指令下，否则非正常运动）。
- 四点法脚本函数码垛：官方有脚本示例。

## 焊接工艺包（插件 WeldingTools，CS 2.13.0+，不可与摇杆套件同用）
- 激活：设置-系统-Elitecos → + 选择 WeldingTools-1.5.0.elico → 激活（输入激活码，试用 1-100 天/正式永久）。
- 配置：配置-插件-焊接设置：焊机匹配=通用 I/O / 脚本 / 总线协议（Modbus）；通用 I/O 信号=起弧、手动送气/送丝/退丝、起弧成功反馈、焊机正常、焊接电流/电压（模拟输出）、主电流反馈、寻位使能/反馈；**Job 模式**：焊机 Bit0-3 二进制选任务（例 Job8=1000→DO3=ON），至少 0-7 号、最多 0-15 号。
- 焊接模式：线性焊接、管形焊接、多层多道、点焊。
- 摆动轨迹：月牙、圆圈、锯齿、梯型；圆弧可固定模式/无约束模式（自定义弧角）。
- **TCP 要求（重要）**：TCP 示教必须准确，**Z+ 朝下与焊枪出丝方向一致**，否则可能意外错误；可先示教一个 Z+ 朝下的坐标系，示教 TCP 姿态时选用；若参考基座则需翻转工具末端朝上。
- 焊接时序：预送气 → 起弧（通电流电压+送丝，防粘丝）→ 稳定（主电流，电弧反馈监控）→ 滞后送气（灭弧后继续送保护气防氧化）。
- 焊接工具节点：初始点、接近点、开始点（直线形/过渡点/圆弧形）、离开点、3D 查看器（红=焊接轨迹、蓝=非焊接）、运行流程（循环、空运行速度比率、有效焊道勾选）、仿真模式（虚拟运行仅轨迹规划不实际作业；送气/送丝/退丝手动）。
- 寻位（需焊机支持）：平面/空间寻位（三点+搜索方向点）；工具法兰按钮快速生成焊接路径。
- 焊接快速使用：见官方「焊接快速使用」。

## 力控（CS 外接 / CSF 内致力控）
- CSF 系列末端集成自研力控模块，无需外挂；CS 标准系列需 SensorAdapter 插件 + 外部力传感器（8 芯弯头成型线，物料号 NA20300180）。
- 流程：工具 I/O 配置（RS485 波特率按实际）→ 安装插件 → 力传感器**空载标定**（完成后 Fx/Fy/Fz 接近 0）→ **负载辨识**（4 姿态，只需动 4/5/6 轴；负载辨识后未做清零，在力节点中清零，重启开机也会清零）→ 第三方传感器需**安装角辨识**（建议先装 ≥3kg 负载再做，否则影响结果；完成后拆负载装实际治具再做一遍负载辨识）。
- **力传感器碰撞检测必须开启**（机器人自带碰撞报警仅保护本体，不带传感器会损坏传感器）：设置中先设 10-15N，后期按需调整。
- 编程：锁轴拖动、阻尼设置、力控节点等见官方「CS力控使用教程」「力反馈设备控制机器人」「力传感器插件」「CS力传感器修改空载标定点位」。

## 涂胶 / 轨迹平滑
- 用脚本采集点位生成 .ml 文件（getpoes.script：flag=1 开始采集、2 结束、3 完成；mm_value=点间距 mm；ml_name 文件名的修改）→ 加线程运行。
- 用 remotetcp 插件（remotetcp-1.2.9.0.elico）做**微段插补**：选择 .ml 文件、时间间隔；插件目录-工具路径移动-添加工具路径；运行离线文件（行数/起始行/自动运行脚本移起始点）。
- 抖动解决：插件时间间隔改大；ml 点间距越大速度越快、插件时间间隔越大速度越慢。

## 传送带跟踪（≥2.12.0，增量式）
- 单台机器人最多 2 条传送带。
- 硬件：机器人连接控制柜 **B4 高速 IO**；编码器（以西克示例）：增量式、正交式（需 A、B 两路输入）/升降式/上升/下降（只需 A 输入）；A→高速输入、B→高速输入；+US→24V、GND→0V。
- 用法见官方「传送带跟踪使用」。
