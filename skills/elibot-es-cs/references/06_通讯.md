# 06 通讯（端口 / Modbus / Profinet / EtherNet-IP / Fins / Socket / RS485）

来源：官方「通讯配置」「二次开发-其它语言」https://docs.elibot.cn/cs/e61bf、https://docs.elibot.cn/cs/88fdd/9bd1f

## 二次开发端口（TCP/IP socket，各端口相互独立可同时使用）
- **29999 Dashboard**：机器人的上/下电、切换任务或配置、运行/停止/暂停等。命令以 `\n` 结尾。
  - 常用命令：`robotControl -on`（返回 Powering on）/`robotControl -off`、`brakeRelease`（Brake is released）、`play`（Starting task）、`pause`、`stop`、`task -r`（Task is running）、`task -s`、`task -ss`、`task -p 1.task`（加载任务）、`configuration -p cs1.configuration`、`robotMode`、`robot -t`、`speed -v 50`、`safety -s/-m/-r`、`unlockProtectiveStop`、`closeSafetyDialog`、`popup -s/-c`、`log -a`、`echo`、`version`、`reboot`、`shutdown`、`quit`。
  - 时序注意：dashboard 只负责执行功能不等待完成，短间隔时序依赖命令可能结果异常。
- **30001**：机器人 10Hz 推送状态数据（关节角/速度/力矩、TCP、IO、温度、模式等）；也可发送脚本/运动指令控制。
- **30004 RTSI**：实时数据交互；订阅指定变量以指定频率返回，最快 250Hz；大端字节序；协议=版本校验→设置→同步循环；注意输入/输出订阅方向别搞反。
- **30020 解释器**：脚本排队执行（不打断当前任务）；队列上限 8500；`interpreter_mode`、`end_interpreter`、`clear_interpreter`、`skipbuffer`；状态命令 statelastexecuted / statelastinterpreted / statelastcleared / stateunexecuted / state；ack: <id>: <statements>，discard: <reason>: <statement>（编译错误/任务状态错误/队列超限/清理等）。
- **40011 明文请求**：一问一答式；调用规则同 SEC（不能运动指令、耗时指令、死循环）；建议每次请求 id 不同。
- **30011**：与 30001 类似的数据端口。
- 脚本类型：def=主程序（一次一个，新 def 强制停旧 def）；sec=可并行（不能运动指令、不能耗时指令如 sleep/串口/socket 超时）。
- 模式限制：远程模式才允许外部控制；本地模式强制断开外部连接；普通模式不限制 30001 但无法执行 IO 启动程序功能。
- tcp 连包现象：按报文长度判断完整报文（长度 100 收到 80 需等剩余 20）。

## Modbus
- **机器人做 Modbus TCP 从站**：配置-通讯-Modbus-添加 modbus 设备（IP 为主站 IP）；读线圈（数字输入）、写线圈（数字输出）、读寄存器（功能码 04）、写寄存器（功能码 03）；示教器"添加信号"输入类型/地址/从站地址/频率，图标变绿=连接成功。
- **机器人做 Modbus TCP 主站**：设置客户端 IO（主站读从站/写从站），任务中用信号判断/设置。
- **Modbus RTU 主站**：控制柜端口 / 机器人末端端口（工具 IO 485 配置）。
- 关节电流寄存器：Modbus slave 寄存器地址 95-100（电流），Profinet R2P_Joints 插槽，EthernetIP 105（机器人关节）。

## EtherNet/IP
- 欧姆龙 PLC、汇川 PLC、codesys 与两台机器人（多连接）配置见官方子页；可读机器人关节/状态、IO 交互。
- 数字 IO 可组合为整形寄存器交互（见 04 图形化编程：read_port_register / write_port_register / bit_list_to_integer）。

## Profinet
- 与西门子 PLC 通讯配置：机器人做 Profinet 从站/主站，配置插槽与 IO 映射（官方「CS机器人与西门子PLC的Profinet通讯配置」）。

## Fins（欧姆龙 PLC，插件方式）
- 版本：机器人系统 ≥2.13.4、Fins 插件 ≥2.13.0（fins-2.13.elico）。
- 安装插件 → 配置-Fins 插件：设置 PLC IP → 连接（状态：空闲/连接中/已连接1/已连接2/连接失败；已连接2 需设置 PLC 模式：CV/CS/CJ/CP）→ 勾选自动连接。
- 脚本 RPC：`rpc = rpc_factory("xmlrpc","http://<PLC IP>:9601")`；`rpc.memoryAreaReadInt16("dm100")`、`rpc.memoryAreaWriteInt16("dm100",1)`、`rpc.memoryAreaReadBit("w4.02")["value"]`、`rpc.memoryAreaWriteBit("w4.02",True)`。
- 限制：ROBOT_TO_PLC 方向 DOUBLE/FLOAT/BIT_FORCE/WORD_FORCE 不可用；实时性一般、延迟较大。

## Socket / TCP/IP

- 欧姆龙 Fins 另有专用插件章节。
