## 程序编写建议
1. **命名**：`程序名称（工站/工件型号）+ 日期`。
2. **Move 指令规范**：Move 下只写路点，不允许嵌套其他指令；路点名称改成动作名（吸料点/吸料上方点/抓料点/放料点/放料上方点…）。
3. **主程序规范**：只写逻辑指令（不写运动指令）；主程序里加循环，防止有人改循环模式导致无法运行。
4. **初始化程序**：信号初始化、变量初始化在开始前执行。
5. **文件夹指令**：重复信号点位（抓手/吸盘）用文件夹组织（CS 无法调用子程序）。
6. **循环程序使用**：CS 用 Python 编写，**无法使用跳转功能**，用循环实现。
7. **死循环必须加 ≥0.1s 延时**，否则 CPU 过载卡死。

## 跳转实现方法（无专用跳转指令）
- **方案一 IF 分支嵌套**：双分支跳转（信号A=1 跳路点10，=0 继续）。逻辑直观、调试快；分支多时冗余。
- **方案二 循环+IF+计数法**：CNT 计数标签标记执行节点，while + if 判断，支持任意条件（大于/小于/范围/多信号组合）；"从上到下依次匹配，仅执行第一个满足的分支"。
- **方案三 循环+开关分支+计数法**：while + switch 匹配 CNT 值；结构整齐，但仅支持"等于"匹配。
- 注意：CNT 需提前初始化；外部信号需稳定；循环需终止条件；先测单分支再测多分支。

## 赋值指令与深度复制
- Python 语义：直接赋值=引用（a、b 指向同一对象）；`copy.copy()`=浅拷贝；`copy.deepcopy()`=深拷贝。
- 任务树赋值指令：勾选**深度复制**后，b=a 再改 b，a 不受影响；不勾选则 a、b 同步变动。
- 脚本示例：
  ```python
  a = [1,2,3,4,['a','b']]
  b = a                # 引用
  c = copy.copy(a)     # 浅拷贝
  d = copy.deepcopy(a) # 深拷贝
  ```
- 注意：配置-变量里**不能写入二维数组**。

## 快速修改全局变量
- 示教器仅支持单次手动建单个变量 → 大批量用文件方式：
  1. **系统配置文件**：SFTP（root/elibot）打开 `xxx.configuration.variables`（如 default_test.configuration.variables），复制粘贴修改保存，重开配置文件生效。
  2. **文件导入**（仅 2.15+）：写 `.variable` 文件，格式 name(名称),value(值),remarks(备注),favorite(是否标星)，如 `grid_rows,4,网格行数,false`；U 盘→文件管理器→复制到本地盘→配置-全局变量-导入变量→勾选/确认。
  - 注意：任务运行中点击导入会停止任务；值支持带引号字符串（支持 Python 字符）；非法名称会被系统修正；备注超长截断；特殊字符需满足 xml 转义写法。

## 快速修改点位
- 复制粘贴点位保持**关联性**：复制 home 点→粘贴多处，改一个 home 其余同步更新。
- 批量修改：选中点位→编辑位姿→Z 坐标箭头（左箭头减 mm、右箭头加 mm）→输入数值回车→确认。
- 可变路点：配置-全局变量-编辑位置变量数组 `[x,y,z,rx,ry,rz]`（m）。
- 大变动建议直接删除变量、保存新的当前位姿改回原名称。

## 轨迹节拍优化
- 点位优化：删减冗余无效走位。
- 外部信号交互优化：精简无效等待，按设备实际响应阈值调延时（如真空吸附 1s→0.5s）。
- 轨迹转接优化：过渡点开启**转接半径**（默认 50）；**精准作业点位（工艺关键点）禁止设置转接半径**；若下一节点不是连续运动指令可能抖动。
- 速度/加速度：关节最大 230°/s、1200°/s²；直线最大 1500mm/s、10000mm/s²；运行倍率 100%；短距离过高加速度会抖动；真实速度=设定速度×运行倍率；路点默认勾选「继承参数」。
- 权限：配置-机器人限制调整为最低阈值（首次需设置安全密码，点右上角 logo）。
- 运动模式：姿态变化大（RX/RY/RZ 大幅变动）用关节运动；仅 XYZ 位移用直线运动；规避 6 轴 180°/360° 大旋转（可用旋转气缸替代）。

## 运动到达时提前触发信号
- 事件+标志位方案：路点 2 用 Until 已到达路点模式 → 到达后标志位置 0；事件判断标志位 + `point_dist()`（直线距离，不含姿态）或 `pose_dist()`（含姿态）距离 < 设定值 → 触发 IO。
- 脚本：
  ```python
  def trigger(P,L,O):
      global flag
      if flag==1:
          pose1=get_actual_tcp_pose()
          l1=point_dist(P,pose1)
          if l1<L:
              set_standard_digital_out(O,False)
              flag=0
  ```

## 轨迹复现
- 复合-轨迹记录：开始记录→拖动（按住示教器背部拖动按钮）→停止记录→启动复现。
- 最大 141330 个点位；复现时速度需 100%；报警/下电等状态改变自动结束记录；轨迹文件默认 trajectory，重名自动累加 trajectory_1/2…；重新记录覆盖原文件。

## 初始化判断自动回原位
- 用 `get_actual_tcp_pose()`（单位 m）判断当前处于哪个工作区域（取料区/放料区），按区域避干涉回安全点。
- 工作区域判定：手动移到区域最左/最右/最后/最前端，记录 x、y 最大最小值，用条件判断（如 `2.56<X<264.65 and -793.43<Y<-161.23`，注意程序内单位为 m）。
- 上升安全高度建议把**安全点的高度赋值给当前位置 Z**（不要 Z+ 偏移抬升，可能有上方干涉物）；回安全点速度建议 100mm/s 直线运动；安全点高度须在任何位置都安全。

## 读写内部文件
- 标准柜 A9（3 网口）：共享目录 x86 `/home/elite/user/program` ↔ A9 `/rbctrl/EliRobot_share/program/`（2.5+）。
- D9 柜（1 网口）：`/rbctrl/RT_CONTROLLER/ROBOT/program/`。
- 用 Python 文件 API（open/write），注意缩进；可做自定义日志（时间+自定义内容，同步显示到示教器）。
- 常见问题：读写不成功检查目录、权限、路径。

## 查看关节力矩
- 指令 `get_joint_torques()` 获取 1-6 关节实际力矩（N·m）。
- 电流换算：关节力矩(N·m)=（关节电流/关节额定电流）×额定力矩/减速比；例 CS612 关节2：M=电流×22.679（额定 19.1A、额定力矩 3.58N·m、减速比 121）。
- 各型号各关节综合系数见官方文档；额定电流 0x64、减速比 0x51、额定转矩 0x62（专家模式-伺服参数）；电机峰值电流建议不超过额定 1.5 倍。
