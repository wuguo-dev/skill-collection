# 10 故障处理

来源：官方「故障处理」https://docs.elibot.cn/cs/5f00a

## 专家模式入口
- 示教器右上角 logo/空白处**连续快速点击 5-8 次** → 输入密码 **elibot** 进入专家/开发者模式。
- 专家模式可看：伺服参数（0x51 传动比、0x62 额定转矩、0x64 额定电流、0x74 固件版本、0x7E 抱闸类型、0x0A 写参数）、硬件界面（急停/防护停止状态，≥2.13）。

## 常见故障代码（节选）
- **E6S42 机器人连接断开**：本体与控制柜通讯断开；查线缆、控制柜连接。
- **E12S75{joint} 关节编码器读取异常** / **E12S60{joint} 关节编码器读取异常**：编码器通讯；查接头/线缆/编码器。
- **E12S21{joint} 关节驱动器过流**：驱动器电流超限；查机械卡滞/负载/驱动器。
- **E6S100 安全违规处理**：安全回路违规（急停/防护停止/安全 IO 双通道不一致等）。
- **E2S2 急停无法消除快速排查**：急停回路未复位/双通道不一致；查 EI 通道与按钮。
- **E6S48 机器人上电失败**：查供电/抱闸/控制柜供电方式（MINI 柜未配置供电方式会触发 E6S52）。
- **E12S903 关节开抱闸异常**：抱闸释放失败；查抱闸类型设置（0x7E/0x0A）、抱闸盒强制释放。
- **E6S25 主板紧急停止安全输入IO信号切换不一致**：主板急停输入两通道状态不一致。

## 通用排查方法
- **机器人不运动**：查模式（远程/本地/普通）、任务是否运行（task -r / /io_and_status_controller/robot_task_running）、速度缩放是否为 0、是否暂停/停止/保护停止、点位是否在工作范围内且可解、单位是否 m/rad。
- **机器人抖动**：查转接半径设置、加速度过大（短距离）、涂胶/微段插补时间间隔。
- **机器人碰撞报警处理**：查碰撞灵敏度（40-80% 常用）、外力/干涉；灵敏度越小越灵敏（触发力越小）。
- **撞击卡死处理方法**：断电、手动（抱闸盒）释放、回打包位/安全位、检查机械。
- **故障状态下回打包位**：官方有流程（断电/抱闸盒配合）。
- **取消关节自动标定**：官方「取消关节自动标定」。

## 运维技巧
- **机器人序列号绑定说明**：软件/激活与序列号绑定。
- **重置操作模式密码与安全密码**：
  - 方法1：魔术文件（U 盘根目录建 `elimagic/` 文件夹放入 .sh）→ 插入 USB → 等提示运行完成（左上角 USB 变红）→ 拔出 → 重启；结束后删除 U 盘 elimagic 文件防反复触发。密码文件需联系艾利特技术人员获取。
  - 方法2：SFTP（Notepad++ 等，root/elibot）登录 → 删除 `/home/elite/EliRobot/conf` 下 elipass（操作模式密码）/ elisafetypass（安全密码）→ 重启 → 重新设置密码。
- **通过魔术文件强制修改 IP**（≥2.10.0）：U 盘 FAT 格式根目录 `elimagic/elimagic_change_ip.sh`（默认改为 192.168.1.110，可改文件内 IP）→ 插入示教器或控制柜 → 等待自动执行 → 正常模式=成功。
- **old 文件恢复 task 文件**（≥2.12）：保存后同目录生成 `xxx.number.old`（number 0-9，越小越新，同文件名最多 10 个）；U 盘拷出改后缀 .old→.task 再传回；或在示教器打开 .old 文件→另存为。
- **CS机器人打包 / CS日志查看插件 / 支持文件导出及分析**：打包现场数据供技术支持；日志插件查看；文件导出分析。
- **CS机器人通信报警排查（E1S2/E1S3/E1S4）**：网络/端口排查流程。
- **机器人进入恢复模式的处理方法 / 机器人应用升级失败 / 机器人无法开机问题处理 / 黑屏点击触摸屏无反应处理 / 虚拟机问题**：见官方子页。
- **本机 TCPIP 软件与虚拟机连接 / 远程无线控制机器人**：见官方「常用工具」子页。
