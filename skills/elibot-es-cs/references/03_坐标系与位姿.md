## 三类坐标系
- **基座标系**：以机器人安装基座为基准的直角坐标系，右手准则（面对机器人：前后 X、左右 Y、上下 Z）。任何路点最终在基座下运行。
- **用户坐标系**：用户对作业空间自定义的直角坐标系。3 点法示教：先示教**原点**，再示教 **X+**、**Y+** 正方向点，Z 按右手定则=平面法向。用于示教执行、位置补偿指令执行。
- **工具坐标系 TCP**：以工具末端为控制点。位置用 **4 点法**（4 种差别大的姿态戳同一固定尖点，建议 X+、X-、Y+、Z- 四个方向；4 点姿态差别太小状态 LED 变红）；姿态用「示教姿态」从下拉坐标系对齐方向。
  - 验证 TCP：尖点对准固定尖点，切到新 TCP 旋转 RZ，两尖点始终对齐=标准；偏差随角度变大=不标准需重示教。
  - 默认 TCP 在法兰中心。

## 位姿与单位
- 位姿 = 位置 + 姿态，数组顺序 `[x, y, z, rx, ry, rz]`。
- **单位：XYZ=米(m)，RX/RY/RZ=弧度(rad)**。
- `r2d()` 弧度转角度、`d2r()` 角度转弧度。

## 常用变换函数
- `get_actual_tcp_pose()`：当前 TCP 位姿（基座下，m/rad）。
- `pose_trans(p1, p2)`：复合位姿变换。
- `pose_inv(p)`：位姿逆。
- 基座→用户：`var := pose_trans(pose_inv(用户坐标系), get_actual_tcp_pose())`
- 用户→基座：`var := pose_trans(用户坐标系, var_1)`
- 例：获取用户坐标系下位姿并抬 Z 20mm：
  ```python
  var_1:= pose_trans(pose_inv(坐标系_1),get_actual_tcp_pose())
  var_1:= [var_1[0],var_1[1],var_1[2]+0.02,var_1[3],var_1[4],var_1[5]]
  MoveL var_1
  ```
- 自定义用户坐标系偏移函数：
  ```python
  def Offs(p,x,y,z,user=[0,0,0,0,0,0]):
      out = p.copy()
      out_in_user = pose_trans(pose_inv(user),out)   # base -> user
      out_in_user[0] = out_in_user[0]+x
      out_in_user[1] = out_in_user[1]+y
      out_in_user[2] = out_in_user[2]+z
      out = pose_trans(user,out_in_user)             # user -> base
      return out
  ```

## 偏移指令（V2.13.0+ 推荐）
- 位置：任务界面右侧**复合**目录 → 偏移。
- 编辑界面：标识1=接收偏移后点位的变量；标识2=基准路点/变量（**未示教的点位、不含 6 个元素的 list 变量不会出现在列表**）；标识3=按**位姿**偏移（沿 XYZ 坐标）还是按**关节数据**偏移（关节角度）。
- **常量偏移**：输入固定距离（如 X 右侧输入 100 = X 方向偏移 100mm），不能在程序中加减。
- **变量偏移**：偏移值=6 元素数组 `[x,y,z,rx,ry,rz]`，如 `[0.1,0,0,0,0,0]`=X+100mm；数组加减可实现阵列/码垛：`var_2[0] = var_2[0] + 0.1`。
- 运行：新增路点，路点类型=**可变位置**，选择偏移指令里添加的变量。
- **规则（撞机风险）**：
  1. 位姿偏移的点位 → 移动类型必须 **MoveL**；关节数据偏移 → **MoveJ**。位姿偏移点用 MoveJ 运行会撞机。
  2. 偏移后的点位自动转为基座坐标，MoveL 的坐标系必须选**基座**。
  3. 基于坐标系偏移：配置里添加用户坐标系，偏移指令先把基准点转成用户坐标系下的点→偏移→转回基座。
- 自身姿态 vs 工具：自身姿态以机器人**当前姿态**的 TCP 朝向偏移；工具以**基准点的姿态**偏移。

## 可加减限制（重要）
- 基座/用户坐标系下：只能加减 x/y/z/rz 四项，**rx/ry 不能直接加减**；工具坐标系下六项均可加减。
- 注意偏移后点位所在坐标系与移动指令配置是否一致。

## 其他
- **指令中设置 TCP**（2.11.0+）：设置-设置TCP；只影响配置了「使用激活的 TCP」的路点；设置 TCP 时上方设置动作需选任意一个，否则节点橙色无法完成设置；测试按钮只作用于手动模式，自动运行按路点指令设置的 TCP 运行。
- **奇异点**：机器人奇异姿态下控制受限/报警，注意规避（官方「机器人奇异点」）。
- **负载重心设置**：配置-负载。
- **观察坐标系**、**获取用户坐标系下当前位姿**、**自动对齐**：见官方子页。
