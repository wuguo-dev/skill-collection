# 08 ROS2（CS_ROS2 软件包）

来源：官方「ROS」https://docs.elibot.cn/cs/1ffff

## 环境与安装
- Ubuntu 22.04 + ROS2；连接 FB1 与 FB2 两个网口到上位机；尽量关闭远程控制（或保持远程模式）。
- 安装 SDK：`git clone https://github.com/Elite-Robots/Elite_Robots_CS_SDK` → `mkdir build && cd build && cmake .. && make -j && sudo make install`（ROS2 源码与 SDK 不建议放一起）。
- 安装驱动：在 elite_ros_ws/src 下 `git clone https://github.com/Elite-Robots/Elite_Robots_CS_ROS2_Driver.git`。
- 构建：`sudo rosdep init` → `rosdep update` → `rosdep install --ignore-src --rosdistro $ROS_DISTRO --from-paths src -y` → `colcon build` → `source install/set.bash`（colcon 缺失时 `sudo apt install python3-colcon-common-extensions`）。
- 国内访问 GitHub 慢，需多次尝试。

## 启动驱动
```
ros2 launch eli_cs_robot_driver elite_control.launch.py robot_ip:=<机器人IP FB1> local_ip:=<电脑IP> cs_type:=cs63 launch_rviz:=false headless_mode:=true
```
- 参数：cs_type（cs63/cs66/cs68/cs612/cs616/cs620/cs625/cs66a/cs520h/ls65 等）、robot_ip、local_ip、headless_mode（true=无示教器任务方式下发外部控制脚本，机器人通常需远程模式）、initial_joint_controller（默认 scaled_joint_trajectory_controller）、tf_prefix（多机器人前缀）。
- 首次连接建议 launch_rviz:=true 验证姿态同步，一致后再改 false。

## 控制器（ros2_control）
- 默认加载：joint_state_broadcaster、io_and_status_controller、speed_scaling_state_broadcaster、force_torque_sensor_broadcaster、tcp_pose_broadcaster、scaled_joint_trajectory_controller（active，推荐）；forward_position_controller、freedrive_controller（inactive）；forward_velocity_controller。
- **scaled_joint_trajectory_controller**：读取 `speed_scaling/speed_scaling_factor`，按机器人实际速度缩放同步轨迹进度；推荐真实机器人使用。Action：`/scaled_joint_trajectory_controller/follow_joint_trajectory`，类型 control_msgs/action/FollowJointTrajectory。
- 关节名：`shoulder_pan_joint, shoulder_lift_joint, elbow_joint, wrist_1_joint, wrist_2_joint, wrist_3_joint`（tf_prefix 时加前缀）。
- 命令行示例：
  ```
  ros2 action send_goal /scaled_joint_trajectory_controller/follow_joint_trajectory control_msgs/action/FollowJointTrajectory "{trajectory: {joint_names: [shoulder_pan_joint, shoulder_lift_joint, elbow_joint, wrist_1_joint, wrist_2_joint, wrist_3_joint], points: [{positions: [0.0, -1.57, 1.57, 0.0, 1.57, 0.0], time_from_start: {sec: 5, nanosec: 0}}]}}"
  ```
- 上电/运行：
  ```
  ros2 service call /dashboard_client/power_on std_srvs/srv/Trigger "{}"
  ros2 service call /dashboard_client/brake_release std_srvs/srv/Trigger "{}"
  ros2 service call /dashboard_client/play std_srvs/srv/Trigger "{}"
  ros2 service call /dashboard_client/robot_mode eli_common_interface/srv/GetRobotMode "{}"
  ros2 service call /dashboard_client/unlock_protective_stop std_srvs/srv/Trigger "{}"
  ```
- 控制器切换：同一时间只能一个关节运动控制器 active；`ros2 control switch_controllers --deactivate ... --activate scaled_joint_trajectory_controller`。
- 排查命令：`ros2 control list_controllers`、`ros2 topic list`、`ros2 action info /scaled_joint_trajectory_controller/follow_joint_trajectory`、`ros2 topic echo /io_and_status_controller/robot_task_running`、`ros2 topic echo /speed_scaling_state_broadcaster/speed_scaling`（为 0 或任务未运行→轨迹不执行）、`ros2 topic echo /joint_states`、`ros2 topic echo /io_and_status_controller/io_states`。
- 注意：发送轨迹建议包含当前位置作为第一个轨迹点；forward_position/velocity 不负责规划与碰撞检查；freedrive 前先停用其他控制器。

## MoveIt2
```
ros2 launch eli_cs_robot_moveit_config cs_moveit.launch.py cs_type:=cs66 launch_rviz:=true headless_mode:=true
```
- Rviz 中拖动末端球体 → Plan / Plan & Execute；示教器实时同步；姿态不一致重启驱动与 MoveIt2 节点。

## Gazebo 仿真
```
ros2 launch eli_cs_robot_simulation_gz cs_sim_control.launch.py
ros2 run eli_cs_robot_simulation_gz gz_control.py --example
ros2 launch eli_cs_robot_simulation_gz cs_sim_moveit.launch.py
```
- 仿真前关闭其他机器人端连接。

## C++/Python 案例
- 监听数字信号沿固定线路搬运案例（FollowJointTrajectory action + set_io 服务 + 订阅 /joint_states、/io_and_status_controller/io_states）：代码在 `eli_cs_robot_driver/example/cpp`，需在 CMakeLists.txt 添加 add_executable/ament_target_dependencies/install 后 colcon build。
- Python 示例：`ros2 run eli_cs_robot_driver safe_joint_move.py --target 0 -1.2 0 -1.57 0 0 --max-vel 0.5 --min-time 2.0 --controller scaled_joint_trajectory_controller`。
- 常见问题：rviz 机器人全部在原点=位姿读取失败，检查连接/同网段/远程模式/headless 参数。
