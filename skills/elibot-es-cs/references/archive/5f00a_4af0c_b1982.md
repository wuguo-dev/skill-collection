# old文件恢复task文件

URL: https://docs.elibot.cn/cs/5f00a/4af0c/b1982
发布时间: 2026-01-13

# 1.简介：



≥2.12版本添加后缀为old的文件，在修改保存过的任务后，会在同目录下有xxx.number.old版本。xxx 是任务名，number是版本号，0-9数字越小代表时间越近的版本，越大则是越早的版本。



# 2. 操作流程



2.1通过U盘修改



1：打开文件管理器，选择“备份文件*old” ,找到需要修改的版本文件，使用U盘拷贝出来，使用电脑修改后缀为“task“
