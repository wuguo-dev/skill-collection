# 虚拟机安装插件

URL: https://docs.elibot.cn/cs/fd2cf/0ab86/3b419
发布时间: 2026-01-15

# 1. 简介



本文主要介绍 CS 系列机器人虚拟机环境下各类插件的安装方法与操作步骤。



# 2. 操作流程



## 2.1将插件移至虚拟机内



1. 示例-插件：RegisterMonitor-1.2.6.0



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_129476_OI8-WH2bsL_rKQtI_1720750902?w=302&h=41&type=image/png)



2. 示例-虚拟机版本：2.12.0



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_445749_W8t96IBbV_eY33j9_1720750956?w=173&h=122&type=image/png)



3. 打开对应的虚拟机文件目录 ，将插件拖到主文件夹-elisim-CS_SIMULATOR_V2.12.0-SIMULATOR-EliRobot-progra     ![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_391406_Od41A3czCofg2MuB_1720751591?w=1050&h=765&type=image/png)



4. CS_SIMULATOR_V2.12.0-SIMULATOR为当前文本示例，使用的版本所在目录。实际使用时，根据当前所使用的版本，选择对应的文件夹。![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_368834_ReiP7mWB4LT9-9li_1720752487?w=974&h=494&type=image/png)



## 2.2打开虚拟机，安装插件



1. 退回到 SIMULATOR 目录下（ elisim-CS_SIMULATOR_V2.12.0-SIMULATOR）右击鼠标，选择在终端打开。输入 ./run_elisim.sh或者点击Tab键补全，点击回车，打开机器人软件。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_850219_hDZRTpuccBuXz9OH_1720752818?w=765&h=468&type=image/png)



2. 打开机器人软件后，点击右上角艾利特log点击设置



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_621223_LjqhxCLpfg0pyyXW_1720753388?w=1280&h=831&type=image/png)
3.点击ELITECOs 点击加号。   ![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_975293_-l5GuZW0QolmT1ie_1720753606?w=1274&h=798&type=image/png)4. 选择对应的插件，点击打开。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_94805_3b16hyvFU3krs8gR_1720753956?w=1217&h=800&type=image/png)



5. 点击重启，再重新打开一遍机器人插件。重新打开后，插件生效。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_888268_3cc230e1vmWslVpQ_1720753996?w=1208&h=797&type=image/png)



## 2.3插件的删除



1. 点击右上角艾利特log点击设置。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_621223_LjqhxCLpfg0pyyXW_1720753388?w=1280&h=831&type=image/png)



2. 点击ELITECOs 。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_76499_31hgCnWWGXTbYASY_1736127219?w=1283&h=801&type=image/png)



3. 找到自己需要删除的插件，点击删除。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_923770_qHFEEKi_GAv9M1sX_1736127297?w=1283&h=794&type=image/png)



4. 点击重启，再重新打开一遍机器人插件。重新打开后，插件生效。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_888268_3cc230e1vmWslVpQ_1720753996?w=1208&h=797&type=image/png)



# 3. 常见问题解答



## 3.1. 机器人软件打开方式



1. 红框处为后续添加的机器人软件。![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_368834_ReiP7mWB4LT9-9li_1720752487?w=974&h=494&type=image/png)



2. 红框处为虚拟机系统自带的机器人软件。如果使用虚拟机自带的机器人软件，直接双击打开对应图标，即可打开机器人软件。![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_484449_rkTBhjexVYuy924s_1720755118?w=1896&h=392&type=image/png)如果使用自带的机器人软件，直接点击红箭头处的EliRobot，把需要的插件放在该目录下的program目录里。文件路径：主文件夹-elisim-EliRobot-program
