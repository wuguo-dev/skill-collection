# E2S2急停无法消除快速排查

URL: https://docs.elibot.cn/cs/5f00a/8d548/c469e
发布时间: 2026-01-13

# 1. 简介



客户现场出现的急停报警无法消除的情况，此文档目的是针对该故障进行快速排查，提高定位效率。



# 2. 操作流程



## 2.1. 示教器排查



1. 首先确认现场示教器的急停按钮处于松开状态。



2. 确认示教器界面里是否配置了安全IO(报警代码:E2S2)。

3. 示教器交替更换：将正常使用无异常的示教器与当前示教器进行更换操作，确认示教器里的急停回路是否异常（该操作可最后排查）。



## 2.2. 控制柜排查



![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ0NjIxLCJwYXRoIjoiMjAyNjAxMTUtMzI5NDk3Ny1hYzUybTUiLCJ0aW1lc3RhbXAiOiIyMDI2LTAxLTE1VDE0OjIzOjExLjYxMSswODowMCIsInRva2VuIjoiIn0sImV4cCI6IjIwMjYtMDgtMDlUMTU6NTk6NTkuOTk5WiIsInB1ciI6Im9yZ2FuaXphdGlvbl83OG5jejN6LS1tYWluLXZlcnNpb24ifX0--960c7f123378f542fbc1dd36490a4d0760e0df05c6950af38b89ea1d4016b4f7/20260115-3294977-ac52m5)

1. 首先使用万用表的“蜂鸣器”档位测回路通断——分别测量（24V-EI0，24V-EI1；引脚）“图-1”的1号位置的外部急停回路是否成功短接或是否有接触不良。



2. 如 示教器急停旋钮和外部急停回路通断均无异常，则使用万用表"直流电"档位——测量“图-1”的2号位置（PWR-GND）引脚的电压是否为24V左右（注意；在测量此引脚的时候可以把接线端子拔掉），如不正常即可确认SafeIO版卡异常。



3. 如以上均无异常，则使用万用表“蜂鸣器”和"直流电"档位——分别排查“图-1”的2号位置测试（24V-0V；引脚）是否有回路和是否有24V电压（注意；需要把端子排插上，确保和（PWR-GND）引脚相通），如无电压，如在有回路的情况下无电压或电压低和24V相差较远，可以排查是否有外部设备短路或者有高电阻干扰。



4. 如以上均无异常，则可拔掉急停回路的黄色端子排，使用万用表"直流电"档位——排查“图-1”的1号位置分别测试（24V-EI0，24V-EI1；引脚）是否有24V电压，如无电压，可检查“图-1”的3号位置的保险丝拆下来查看保险丝是否已经熔断。



供电顺序：SafeIO板卡从PWR/GND引出——IOPower下的24V/0V——保险丝——Safety IO
