# 焊接快速使用

URL: https://docs.elibot.cn/cs/1b89f/756ca/3375a
发布时间: 2025-12-24

# 1. 简介



艾利特开发的焊接工艺包是一套提供标准化焊接解决方案的插件，通过预置焊接 参数、工 艺步骤和智能控制等，可快速创建点焊、管道焊接或多焊道焊缝，实现 焊接工具与任务的自动化控制，最大化降低人为失误的可能性，实现焊接质量全程 可追溯。



# 2. 功能介绍



焊接工艺自定义配置：根据需求自定义焊接与工艺参数，为执行焊接任务提供条件。



全流程工艺控制：支持多种焊接模式（线性焊接、管形焊接、多层多道、点焊）；支持多 样化摆动轨迹（月牙、圆圈、锯齿、梯型等，圆弧轨迹提供固定模式与无约束模式）；支 持JOB模式调用，节省焊接参数配置成本，提升焊接效率；兼容多种焊机类型（通用I/O、 GYS、AOTAI、MERKLE、KEMPPI、MEGMEET 等），灵活性强。



智能辅助功能：寻位（需焊机支持），支持焊接前在平面或空间内自动识别和定位工件的 位置，提升定位精度；可通过工具法兰按钮快速生成焊接路径；可视化模拟焊接路径，有 利于提前调整规避碰撞风险。



# 3. 操作流程



使用焊接工艺包插件的流程主要包括安装、配置、创建任务、生成焊接程序等步骤，具体 流程可参考用户手册中图1-1“焊接工艺使用流程”。同时，需特别注意点焊、角度设置等功 能对TCP的精度及方向有严格要求，务必确保当前使用的TCP示教准确，TCP的Z+方向须 朝下，与焊枪出丝方向一致。



## 3.1 安装



机器人示教器开机后，点击右上角图标进入「设置」，随后点击「系统」 > 「Elitecos」 进入插件激活界面，点击“+”图标，选择“WeldingTools-1 .5.0.elico”插件并打开，点击「未 激活」找到导入的插件后点击「激活」，输入激活码（试用期1-100天，正式版本永久有 效），重启示教器完成安装。



## 3.2 配置



焊接：在「焊接」页面选择焊机匹配类型（通用I/O模式、脚本、总线协议）以激活和控 制焊机。通用I/O模式下需进行焊机匹配（输入/输出信号配置、Job模式）和焊接参数（焊 接电流/电压比例设置、起弧设置、灭弧设置）配置；脚本模式通过运行脚本启动焊接电源， 需加载焊接开始/结束脚本；总线协议支持Modbus等，可适配多种焊机，需激活并输入焊 机IP地址等信息。



电弧设置：可自定义起弧超时时间、灭弧超时时间、电弧丢失超时时间、尝试重新起弧次 数、起弧等待时间等焊接行为参数。



外部设备：在「外部设备」页面配置外部按钮或工具（如Co-pilot或easyTeach工具），包 括输入/输出（开始按钮、焊接中指示灯）和焊接工具的配置，启用前需配置工具I/O锁。



保存配置：完成配置后，点击界面右上角的「保存」 > 「配置另存为」，将所有设置保存 至配置文件中。



## 3.2 任务



焊接参数插件节点：点击「插件」 > 「焊接参数」进入界面，设置前须先在「配置」 > 「焊接」界面选择对应的焊机配置类型并激活焊接电源。通用I/O模式下，Job模式禁用时 可设置焊接电流值（A）和电压值（V）（输入范围均为[0,10]），或勾选「焊接参数启用」 配置起弧和灭弧相关参数；启用Job模式则输入Job任务号。通过通信协议连接焊机时，激 活后为焊机选择需要使用的Job号，各焊机可调用的Job任务号范围不同（如GYS为1-500， AOTAI为0-100等）。



焊接工具插件节点：点击「插件」 > 「焊接工具」进入起始页，包含焊接程序模版（焊接、 点焊、管、多层多道、寻位）和辅助功能（偏移、3D、运行流程）。涉及MoveJ-初始点 （设置基准起始位置）、焊接节点（创建单个焊道路径，包含接近点、开始点、直线型、 圆弧形、过渡点、退出点等，可进行向导、参数、偏移设置）、接近点（设置到达焊接起 点的路径）、开始点（焊接路径起点，支持直线形、过渡点、圆弧形等点位类型）、离开 点（设置离开工件的路径）、3D查看器（查看焊道轨迹）、运行流程（控制程序执行方 式）、利用工具创建程序（通过末端工具按钮创建）、仿真模式（虚拟运行或实际作业） 等内容。



## 3.3 焊接程序



焊接：基础焊接焊道。



点焊：用于工件的快速固定和粘连，单个点焊节点至少需要一个焊接点，支持添加多个焊 接点和过渡点，需确保TCP校准准确且焊枪方向与Z+轴一致，可进行向导、参数（回退、 焊接时间）、焊接点设置。



管：用于管板焊接或管端焊接，标准管道焊接节点包含管节点、接近点、开始点、圆弧形、 退出点，预先设置延伸到360度圆的圆形段，示教时只需设置通过点和结束点即可创建整 个圆。



多层多道：支持创建并管理由多个叠加焊道组成的复合焊道，第一个焊道为基准焊道，可 在「焊道管理」界面编辑参数，支持设置等待时间，可通过向导创建基础焊道并生成新焊 道。



其他功能—寻位：用于焊接前自动识别和定位工件位置，需焊机支持，包括快速寻位（沿 固定搜索方向移动，三点示教法确定方向）、平面寻位（平面内任意方向旋转和移动，五 点示教法确定方向）、空间寻位（空间内任意方向旋转和移动，示教6个接触点和3个方向 点确定方向）及清除功能，可设置寻位参数（寻位速度、搜索距离、自动进入和退出参数 等）。
