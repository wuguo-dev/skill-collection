# **1. 简介**

# **2. 操作流程**



## **2.1CS控制柜485接线**



控制柜中配备了可以供用户使用的RS485串口 ，该接口支持的最大波特率为 500Kbps，用户可根据需求按下图配线使用



**CS标准控制柜：**



黑色塑料装置的正反面分别标有 PIN“1 3 5”和“2 4 6”，PIN3 应焊接到 485-，PIN4 应焊接到 RS485+

# **3. 常见问题解答**



1. 机器人末端485通讯和控制柜485通讯有何区别？



除脚本通讯指令不一样外没有区别。



2. 标准柜的485连接器有配吗？



连接器没有附赠，需要自己购买
