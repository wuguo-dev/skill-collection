# 单步运行

URL: https://docs.elibot.cn/cs/d9b09/c276c
Published: 发布时间: 2026-01-15

# 1. 简介



在日常使用中经常会有客户问到我们机器人是否可以进行单步，如何进行单步，为此提供该文档。



# 2. 操作流程



## 2.1方法一，使用断点



![](https://wdcdn.qpic.cn/MTY4ODg1NjU4NjUwNTY0MA_526716_lIApjjyW7GRVM9r__1751360972?w=1284&h=795&type=image/png)



1. 找到需要单步的位置的上一行，点击行号处生成断点



注：（断点区分横线在上或者横线在下）



![](https://wdcdn.qpic.cn/MTY4ODg1NjU4NjUwNTY0MA_859533_x8D0uY0qVhnFeXCX_1752113645?w=57&h=45&type=image/png)：在上时，结束运行上一行指令则会暂停程序，一般在非运动指令时，横线在上



![](https://wdcdn.qpic.cn/MTY4ODg1NjU4NjUwNTY0MA_724703_jgVqObwOZ9QUd1xJ_1752113658?w=46&h=42&type=image/png)：在下时，会运行完当前行指令后暂停程序，一般在运动指令时，横线在下



2. 确认任务处于暂停状态



3. 这时候就可以三号方框的第一个按钮进行单步运行了，下面的按钮依次代表“停止”，“继续运行”



4. 使用完毕之后记得清除断点



## 2.2方法二，使用暂停



![](https://wdcdn.qpic.cn/MTY4ODg1NjU4NjUwNTY0MA_629991_UWNpcdXy900ldwwR_1751361448?w=1282&h=801&type=image/png)



1. 在任务里选择需要单步的语句行，选择“基本”



2. 点击“暂停”指令



3. 确认指令添加到需要单步的位置上一行



![](https://wdcdn.qpic.cn/MTY4ODg1NjU4NjUwNTY0MA_219115_aRSvztrDT0bQi1yo_1751361615?w=109&h=168&type=image/png)



4. 运行程序，运行到该行任务会暂停则点击第一个按钮就是单步执行（下面的按钮依次代表“停止”，“继续运行”）



![](https://wdcdn.qpic.cn/MTY4ODg1NjU4NjUwNTY0MA_547390_H92ApwEobDZAoxeh_1751361892?w=265&h=34&type=image/png)



5. 使用完成需选中任务中的“暂停”指令点击删除



3. 总结



单步是在调试过程中较为常用的功能，运行逻辑是先需要让任务运行，并执行暂停，则会出现单步按钮可以进行单步操作，所以不一定需要通过指令断点实现，只需在合适的位置触发暂停也可进行单步操作。
