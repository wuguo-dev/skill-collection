# 2.使用说明



在python语法中



● 直接赋值：其实就是对象的引用。



a = {1: [1,2,3]}



b = a



# 赋值引用，a 和 b 都指向同一个对象。



![](https://wdcdn.qpic.cn/MTY4ODg1NzUwOTMyOTk4Mw_127015_J3PsF1RYlkCNivjN_1736838339?w=363&h=236&type=image/png)



● 浅拷贝(copy)：拷贝父对象，不会拷贝对象的内部的子对象。



a = {1: [1,2,3]}



b = a.copy()



# 浅拷贝, a 和 b 是一个独立的对象，但他们的子对象还是指向统一对象（是引用）。



![](https://wdcdn.qpic.cn/MTY4ODg1NzUwOTMyOTk4Mw_40385_YT7WFG5wdBtDJxLu_1736838673?w=455&h=274&type=image/png)



● 深拷贝(deepcopy)： copy 模块的 deepcopy 方法，完全拷贝了父对象及其子对象。



a = {1: [1,2,3]}



b = copy.deepcopy(a)



#深度拷贝, a 和 b 完全拷贝了父对象及其子对象，两者是完全独立的。



![](https://wdcdn.qpic.cn/MTY4ODg1NzUwOTMyOTk4Mw_956876_DnWU3dN4fkBU1mnI_1736838780?w=512&h=286&type=image/png)

## 3.2脚本中的用法



### 脚本示例：



```
a = [1,2,3,4,['a','b']] #原始对象
b = a                   #直接赋值，传对象的引用
c = copy.copy(a)        #对象拷贝，浅拷贝
d = copy.deepcopy(a)    #对象拷贝，深拷贝
###########################################################
a.append(5)             #修改对象a
a[4].append('c')        #修改对象a中的['a', 'b']数组对象
 
textmsg("a=",a)
sleep(1)
textmsg("b=",b)
sleep(1)
textmsg("c=",c)
sleep(1)
textmsg("d=",d)

```
