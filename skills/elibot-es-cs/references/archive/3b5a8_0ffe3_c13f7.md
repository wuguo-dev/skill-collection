# 2. 操作流程



（1）磁盘占用率查看方法：安装插件——点击插件——点击EliTerminal——ssh root@ 6.0.0.9的方法进行登录，然后执行df 查看



（2）CPU占用率查看方法：安装插件——点击插件——点击EliTerminal——ssh root@ 6.0.0.9的方法进行登录，然后执行 top 查看Eliserver

# 3. 常见问题解答



（1）：需要注意一下，该插件为内部支持使用插件，客户现场不要保留，支持结束后，请及时卸载该插件，防止客户滥用。



（2）：磁盘满了大概率是磁盘挂载问题



（3）：CPU满了大概率是线程没有加sleep，CPU占用率超过70%以上属于高负载运行。
