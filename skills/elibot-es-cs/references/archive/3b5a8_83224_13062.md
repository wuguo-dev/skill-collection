# 1. 简介



该文档用于CS机器人搭配森萨帕特相机，通过插件的形式进行标定，以及发送接收应用，方便使用，无需繁琐步骤。



# 2. 操作流程



## 1. 安装与准备



### 1.1. 硬件准备



#### 1.1.1. 硬件清单



●  EliteCS机器人



●  sensorpart 相机



●  标定板



●  相机末端法兰



●  M4*10六角螺丝 x 2



#### 1.1.2. 硬件安装



● 安装固定相机到机械臂的末端



● 将相机网口连接到机械臂的FB1网口



● 将相机的电源接到机械臂控制柜的IO或者外接24v以给相机供电



● 24V 棕色



● GND 蓝色
