# 远程开机&通电自启动

URL: https://docs.elibot.cn/cs/ab632/b62ef
Published: 发布时间: 2026-01-15

# **1.简介**



本文主要介绍CS/ES机器人控制柜开机的两种方式，包含通电自启动跟远程开关机，用户无需使用示教器右上角的开关按钮，以满足有些工作场景人为开机不方便，希望可以总闸上电后自动开机或者触发继电器信号后自动开机



# **2.操作流程**



硬件适用：CS或者ES系列机器人，标准柜子、B1控制柜，D9mini控制柜。



软件版本适用：2.14以上



# **方式一**



通电自启动主要用于远程控制机器人控制柜的启动，无需使用示教器右上角的开关按钮，主电源通电后自行启动无需其他操作。



## **2.1通电自启动接线方式：**



### **2.1.1.标准柜、B1柜的接线方式**



找到电控柜的远程开关机接口短接Remote ON和OFF至12V，即可实现通电自启动。

# **方式二**



远程开关机主要用于远程控制机器人控制柜的启动和关闭，无需使用示教器右上角的开关按钮，通过触发继电器信号后自动开机。



## **2.2远程开机接线方式：**



### **2.2.1.标准柜、B1柜的接线方式**



找到电控柜的远程开关机接口，并将按钮或者继电器接入ON或者OFF与之12V接口串联，控制实现开路或者闭路即可实现自动开机或者关机。

### **描述：**



远程ON/OFF功能端子提供12V 辅助电源。在控制柜主电源开关打开，同时控制柜未启动的情况下，功能端子的12V 辅助电源端子将保持带电状态。远程ON 输入接口用于开机，远程OFF输入接口用于关机。



控制柜处于关机状态时，远程ON 输入用于开机，有效脉冲时间为 100-2000ms，不满足有效脉冲时间将无法开机；



控制柜处于开机状态时，远程 OFF 输入用于关机，有效脉冲时间为 100-2000ms，不满足有效脉冲时间将无法关机。



# **3.常见问题解答**



1. 标准控制柜，老款控制柜无需信号触发能开电自启动吗？



可以，但是以上接线的方式不适用，需要烧录特定的固件至电控柜safety IO板内实现，过程比较繁琐需要特殊工具烧录器，如需要配置请联系艾利特技术人员



2. 默认短接了Remote OFF，对应的触发信号的关机功能失效。



3. 电控柜的电源开关需保持接通的状态下通电才有效。
