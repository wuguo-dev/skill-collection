# E12S75{joint} 关节编码器读取异常

URL: https://docs.elibot.cn/cs/5f00a/8d548/ec120
发布时间: 2026-01-13

## 1.简介



E12S75报警所指示的是：{joint} 关节编码器读取异常。其具体释义如下：



1. E代表：大的报警类别范畴。



2. S代表：内部的小类别。



3. 12代表：伺服报警。



4. 75代表： {joint} 电机编码器计数异常 （如下图）

## 2.故障原因



● 电机编码器线缆松动。



● 电机编码器部件不良（主要为：INC PCBA读头损坏，码盘污染，轴承损坏漏油，INC PCBA板与码盘配合异常）。



●  硬件受到干扰。



## 3. 排查及处理方式



### 3.1排查



第一步，本体断电，拆开对应的故障关节的端盖，并重新插拔电机编码器排线。上电，看该问题还有没有，如果有执行第二步。



第二步，点击左上角，打开电源，并释放抱闸（下图为正常打开的状态）。



![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ0NzU1LCJwYXRoIjoiMjAyNjAxMTUtMjc0MzMxOS0xNm1oaW8iLCJ0aW1lc3RhbXAiOiIyMDI2LTAxLTE1VDE0OjQ1OjA0LjU0NSswODowMCIsInRva2VuIjoiIn0sImV4cCI6IjIwMjYtMDgtMDlUMTU6NTk6NTkuOTk5WiIsInB1ciI6Im9yZ2FuaXphdGlvbl83OG5jejN6LS1tYWluLXZlcnNpb24ifX0--efe1766bc6d9e2fe0b23a8c9d052620437d3e409f87552a2113f075fb797cbd0/20260115-2743319-16mhio)



第三步, 针对故障关节，新建任务，编写运转程序，运转几分钟，暂停。



第四步：进入开发者模式，输入密码elibot后,选择伺服参数，选择对应关节伺服。（例如：伺服1故障，如下图。）



![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ0NzU2LCJwYXRoIjoiMjAyNjAxMTUtMzM3NjEyMy1laTJwNzMiLCJ0aW1lc3RhbXAiOiIyMDI2LTAxLTE1VDE0OjQ1OjA0LjY2NyswODowMCIsInRva2VuIjoiIn0sImV4cCI6IjIwMjYtMDgtMDlUMTU6NTk6NTkuOTk5WiIsInB1ciI6Im9yZ2FuaXphdGlvbl83OG5jejN6LS1tYWluLXZlcnNpb24ifX0--add26fd7ef8c80046a7cfca7bcb0d66fb9fa023eee9c2c4d199057a04963a95f/20260115-3376123-ei2p73)

### 3.2处理方式



（1）返厂维修。



（2）现场更换关节。
