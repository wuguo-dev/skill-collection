# 负载重心设置

URL: https://docs.elibot.cn/cs/97375/cf056/8df90
发布时间: 2026-01-15

# 1：简介



## 1.1 负载重心定义



负载即是机器人装在机器人末端外部设备的总重量（单位：kg）；重心即是机器人末端外部设备的重心距离机器人末端中心的距离（单位：mm）。



## 1.2 负载重心意义



负载重心影响机器人的拖动效果，碰撞检测效果，轨迹的准确性，电机寿命等。



# 2. 设置步骤：



点击“配置”，进入机器人参数配置界面



点击通用配置中的“负载”



添加一个新负载，如果只需要用到一个负载那么这一步可以省略



输入实际安装在机器人末端上工具的重量。



设置重心位置以机器人末端通讯接口为参考，指向通讯接口的为Y的负方向，以Y的负方向为参考顺时针旋转90度为X的负方向，以Y的 负方向为参考逆时针旋转90度为X的正方向，与机器人末端垂直且指向外的方向为Z的正方向。



当机器人质量和重心设置好后点击“立即设置”按钮即可。

# 3. 检验



按下示教器顶部自由拖动按钮或末端拖动按钮，机器人末端三色灯亮蓝灯且机器人没有动或者有一点微动那就说明负载以及重心就设置正确；如果机器人往下掉或者往上抬那就说明质量没有设置正确，如果机器人往X,Y,Z三个方向的某一个方向偏那就说明重心没有设置正确。
