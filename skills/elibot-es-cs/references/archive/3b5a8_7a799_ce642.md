# 2. 操作流程



## 2.1插件安装



把插件放在U盘插入示教器U盘接口，点击右上角ELITE图标，再点击设置。



**在插件目录下找到所需插件并下载**



**总线与扩展IO类：**通讯类相关插件；例如socket插件、IO高级配置插件等。



**生态插件：**适配外部生态；例如大寰夹爪插件、巴毅夹插件爪、力控插件等。



**工具类：**机器人自身功能扩展；例如干涉区插件、开机速度控制插件

# 3. 常见问题解答



1、为什么没有找到安装的插件？



无论是安装或者卸载插件都需要重启以后生效



2、更新插件需要把之前的插件卸载吗？插件里的数据会丢失吗？



不需要卸载，直接安装新版本插件会直接覆盖。插件数据不会丢失，插件数据保存在机器人系统配置内。
