# 外部方式卸载CS插件

URL: https://docs.elibot.cn/cs/3b5a8/7a799/5a769
发布时间: 2026-01-16

# 1. 简介



在日常使用中，会碰到安装的插件版本和系统版本不适配的情况，出现这种问题一般是系统API版本较老，插件版本较新，可能导致机器人开机无法进入系统，一直卡在读条界面，这时候就需要通过外部方式卸载掉里面冲突的CS插件。

## 2、通过物理键盘登录



如果客户现场无法连接PC，但有USB接口的物理键盘，此时可以使用下方流程，直接在控制器上进入系统终端内部，登陆后，可以直接在控制器上进行系统终端操作，该操作会直接登陆至X86系统。



该操作与PC连接相同，具体步骤如下：



1. USB键盘插到示教器上



2. 按Ctrl + Alt + F1组合键，会进入登陆系统界面



3. 输入登录用户名 root ，密码 elibot

## 3、魔术文件方式升级系统（只适用于标准柜控制柜）



也可以通过魔术文件强制升级系统，升级到支持冲突插件的系统版本，来实现打开机器人。



1、在U盘根目录下新建名为“elimagic”的文件夹



2、 在微盘中找到魔术文件，拷贝对应功能，例如强制升级elimagic_upgrade.sh 的elimagic文件到步骤1新建的U盘目录中



3、 实现自动升级功能，将最新升级包放到该脚本同一目录中，并将升级包重名为：CS_UPDATE.eup



![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ1MjI1LCJwYXRoIjoiMjAyNjAxMTYtMTc1MDg4LXYyMDh5biIsInRpbWVzdGFtcCI6IjIwMjYtMDEtMTZUMTM6MDg6MjUuMDU4KzA4OjAwIiwidG9rZW4iOiIifSwiZXhwIjoiMjAyNi0wOC0wOVQxNTo1OTo1OS45OTlaIiwicHVyIjoib3JnYW5pemF0aW9uXzc4bmN6M3otLW1haW4tdmVyc2lvbiJ9fQ--53bec1130478357c64471ac23e6c368b1ac9847effc88c89b996e4c10ff4d22b/20260116-175088-v208yn)



4、 将U盘插入到示教器或控制器USB接口中，等待数秒会在上方出现USB标识，和绿色横条，这就是魔术文件开始工作



![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ1MjMyLCJwYXRoIjoiMjAyNjAxMTYtMTc1MDc1LTEyNGZqZiIsInRpbWVzdGFtcCI6IjIwMjYtMDEtMTZUMTM6MDg6MjcuODQ3KzA4OjAwIiwidG9rZW4iOiIifSwiZXhwIjoiMjAyNi0wOC0wOVQxNTo1OTo1OS45OTlaIiwicHVyIjoib3JnYW5pemF0aW9uXzc4bmN6M3otLW1haW4tdmVyc2lvbiJ9fQ--e151f5a4f98ab2f6070b83eeaac178038fdc4dbb13df328f337d8bc379828215/20260116-175075-124fjf)



5、 等待数秒后，界面会有相应的提示，等待提示成功或完成即可，此时会自动重启进入系统，正常进入界面则升级系统成功，没有插件与之冲突



注：为防止自动升级完成后未拔出U盘导致重启后再次自动升级，升级后U盘中CS_UPDATE.eup该文件会自动重命名为：CS_UPDATE_日期_时间.eup,如需再次使用，需手动重名该文件为CS_UPDATE.eup。
