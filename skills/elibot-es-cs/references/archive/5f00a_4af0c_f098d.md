# 通过魔术文件强制修改IP

URL: https://docs.elibot.cn/cs/5f00a/4af0c/f098d
发布时间: 2026-01-13

# 1. 简介



当现场不知道控制柜IP地址（FB1）时，可以通过魔术文件强制修改控制柜IP地址（FB1）。该功能不依赖于控制器软件是否可以正常启动、运行等情况，方便快速恢复现场环境及降低技术支持难度。



●  软件版本要求：



软件版本 >= 2.10.0。



●  魔术文件：。



elimagic_change_ip.sh

##### 2-3、修改IP（可是使用默认IP）

U盘插到示教器或者控制柜都可，插上U盘后魔术文件开始自动修改IP，示教器状态栏会依次进行以下提示，出现正常模式代表修改成功，若无示教器时可以插上U盘等待1~2分钟通过电脑"ping"一下查看能否“ping”通。

# 3. 常见问题解答



##### 1、 插入U盘后无反应



答：检查魔术文件存放路径，是否为根目录下面的“elimagic”文件夹，U盘格式是否正确。
