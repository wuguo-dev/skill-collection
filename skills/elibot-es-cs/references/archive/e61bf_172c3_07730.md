# 机器人做ModbusTcp从站

URL: https://docs.elibot.cn/cs/e61bf/172c3/07730
发布时间: 2026-02-11

# **1. 简介**



在工业自动化中Modbus TCP是常见的一种常见的工业总线协议，艾利特控机器人支持Modbus TCP 从站，本文以modbus poll调试软件跟机器人建立通讯为范例，介绍艾利特机器人Modbus TCP 从站的配置操作步骤



# **2. 操作流程**



机器人做modbus TCP从站，可以使用机器人控制柜的FB1网口或FB2网口（两个都可以用，任选一个，B1柜跟MINI柜已经将两个网口合并到一个网口），本文以FB1为例



### **2.1 网络配置**



2.1.1将网线分别连接电脑的网口跟控制柜的FB1网口，点击示教器右上角【**logo】**，点击【**系统】-【网络】**可进行ip设置



![](https://wdcdn.qpic.cn/MTY4ODg1NzUwOTMyOTk4Mw_850203_T2WSLPpHf9WjAPnb_1714975996?w=1276&h=784&type=image/png)



同时需要将电脑网口IP设置为与机器人FB1同一网段，打开电脑终端ping aaa.bbb.ccc.ddd一下检查网络是否连接正常



![](https://wdcdn.qpic.cn/MTY4ODg1NzUwOTMyOTk4Mw_896440_RJtuBrbwBmn_5EEA_1714976555?w=565&h=238&type=image/png)



2.1.2打开第三方调试软件modbus poll,点击【**connection】-【connect**】,选择modbus tcp/ip,ip地址栏输入机器人的ip，端口默认502，最后点击ok



![](https://wdcdn.qpic.cn/MTY4ODg1NzUwOTMyOTk4Mw_154796_NYWXTZbIkQB20NTZ_1714976899?w=675&h=735&type=image/png)



2.1.3对话框不显示【No connection 】就表明调试软件已连上cs机器人



![](https://wdcdn.qpic.cn/MTY4ODg1NzUwOTMyOTk4Mw_781359_sKt61b1Hzh1Zp5vC_1714977150?w=469&h=307&type=image/png)



### **2.1 机器人Modbus寄存器定义**



机器人支持对线圈和整形寄存器的写入，但部分线圈跟寄存器已经系统功能做的绑定，具体定义可参考数据定义表格，用户客户自定义使用线圈和寄存器如下



用户可使用线圈（软件版本<=2.14.5不支持）：



128个输入，地址：300-427



128个输出，地址：500-627



用户可使用寄存器：



128个输入输出：地址：256-383



48个输入：地址：600-647 （软件版本<=2.14.5不支持）



48个输出：地址：700-747 （软件版本<=2.14.5不支持）

# **3. 常见问题解答**



1. 机器人支持浮点型寄存器吗？



暂时不支持，如果需要写入小数点可以将浮点数x100、x1000倍数，放大成整数数后写入



2. 连接端口支持修改成其他的吗？



软件版本2.15.0以后支持在界面直接修改



3. 寄存器支持写入负数吗？



支持，但是使用Modbus客户时，寄存器的值会默认解析成无符号整数，可以使用脚本命令读取解析成有符号整数read_port_register(256,True)
