# 1. 简介



在客户端如果现场不允许使用U盘，但是需要更新应用造作，可以参考此文档。



# 3. 步骤示例：



### 3.1 下载艾利特应用升级包，版本>2.4.



可以在官网下载，或者向艾利特工程师索取。



### 3.2 下载git bash



可自行下载安装Git-2.33.0-64-bit.exe都选择默认路径默认选项。



### 3.3 安装



打开文件所在的文件夹右键选择Git Bash Here
