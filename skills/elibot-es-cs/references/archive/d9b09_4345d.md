# 轨迹复现功能的使用

URL: https://docs.elibot.cn/cs/d9b09/4345d
Published: 发布时间: 2026-01-15

# 1. 简介



本文档将介绍CS机器人如何使用轨迹复现功能----拖动机器人时，需要记录机器人运行轨迹，运行任务时复现轨迹，适用于喷涂应用。



# 2. 操作流程



1、点击导航栏任务，右侧点击复合下拉选中轨迹记录，点击左下角开始记录，然后按下示教器背部拖动按钮拖动机器人（拖动功能操作方法参考自由拖动和手动移动机器人文档[https://docs.elibot.cn/cs/97375/cf056/ebc64#heading-menu-h1-0](https://docs.elibot.cn/cs/97375/cf056/ebc64#heading-menu-h1-0)）



![](https://wdcdn.qpic.cn/MTY4ODg1Nzc0NTU0NzE0NA_636273_YBCtWDtWkAQTb6vC_1742198516?w=2189&h=1257&type=image/png)



2、 拖动结束后点击停止记录即可



![](https://wdcdn.qpic.cn/MTY4ODg1Nzc0NTU0NzE0NA_93103_YXgBqwGFRE_kz79p_1742199343?w=2189&h=1263&type=image/png)



3、 记录完成，点击启动按钮即可复现轨迹记录情况，在使用轨迹复现功能使，机器人速度需要调整至100%；



![](https://wdcdn.qpic.cn/MTY4ODg1Nzc0NTU0NzE0NA_9993_cs1XTJWU7N4npKS5_1742199437?w=2183&h=1255&type=image/png)



# 3. 常见问题解答



1、 轨迹记录最大可记录141330个点位；



2、 在使用轨迹复现功能使，机器人速度需要调整至100%。



3、 轨迹记录时发生报警、下电等机器人状态、安全状态改变时自动结束记录；



4、 轨迹文件默认名称为trajectory,如果输入或默认名称轨迹文件已存在时将自动命名，命名格式为trajectory_1 trajectory_2一直累加；



5、轨迹文件可选择已有的轨迹文件；



6、重新记录时将覆盖原有文件内容；
