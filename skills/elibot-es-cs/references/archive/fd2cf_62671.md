# 网页示教器使用

URL: https://docs.elibot.cn/cs/fd2cf/62671
Published: 发布时间: 2026-04-08

# 1. 简介



本手册主要介绍 CS 和 ES 系列机器人网页版示教器的登录方法，旨在帮助用户正确登录网页版示教器，实现对机器人的正常操作、程序编辑与任务执行。



适用版本：建议控制器版本 2.14.5及以上



也可以使用远程桌面VNC，参考链接：[https://docs.elibot.cn/cs/fd2cf/ed9bb#heading-menu-h1-0](https://docs.elibot.cn/cs/fd2cf/ed9bb#heading-menu-h1-0)



# 2. 操作流程



## 2.1. 硬件连接



第一步：机器人控制柜网口与 PC 端网口通过网线进行连接，标准控制柜与 D9 控制柜连接方式一致，均接入控制器FB1网口；也可通过交换机中转组网，实现连接。如图 2-1



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_371718_xDY2fmJwVs9Pxprl_1775544585?w=1279&h=1706&type=image/png)



图2-1



第二步-在机器人示教器上点击右上角菜单——点击设置 如图2-2



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_232185_uf7iC1nXUHqtwkjZ_1775544857?w=1280&h=794&type=image/png)



图2-2



第三步-选择网络——网络（静态地址)——输入（IP 地址，子网掩码，默认网关）——点击“应用“（网络已连接则表示连上）如图2-3



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_221079_LudxQE3jontfj8dt_1775546885?w=1280&h=799&type=image/png)



图2-3



## 2.2. 网页登录



打开PC端，在谷歌浏览器 URL 地址栏中输入示教器的网址，http 网址由 IP 地址和端口号两大要素构成，端口号 5800。例如http://192.168.1.200:5800/，点击连接 ，登录界面如图 2- 4所示



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_294003_TEV7qK5SfOsmgDKw_1775548602?w=1606&h=807&type=image/png)
