# 1. 简介

# 3. 常见问题解答



（1）如果你没有“fcitx”选项，先打开终端手动安装fcitx，等安装成功之后再执行上述步骤



sudo apt-get install fcitx



（2）然后设置fcitx为开机自启动



sudo cp /usr/share/applications/fcitx.desktop /etc/xdg/autostart/
