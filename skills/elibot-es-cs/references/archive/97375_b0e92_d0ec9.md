# 屏保设置

URL: https://docs.elibot.cn/cs/97375/b0e92/d0ec9
发布时间: 2026-01-15

# **1. 简介**



本文将介绍如何设置CS机器人示教器的屏保。



需要注意，2.13之前的版本，屏保只有自动锁屏，没有手动锁屏。设置好自动锁屏时间 后，规定时间内示教器没有任何操作，才会锁屏。
