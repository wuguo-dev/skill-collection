# 自动对齐功能

URL: https://docs.elibot.cn/cs/97375/b0e92/e6919
发布时间: 2025-12-22

# 1.  简介



● 自动对齐：使 TCP（工具坐标） 和当前选择坐标系（基坐标/用户坐标），在 XOY 平面保持平行。



# 2.  操作流程



2.1 点击左侧导航栏“1-操作”>“2-选择需对齐的坐标系”>"3-点击对齐"

# 3.  常见问题解答



● 对齐后夹具末端和机台不够垂直？



对齐功能是机器手末端法兰平面与机器手底座平面，在 XOY 平面保持平行。夹具属于后面加装，与机器手底座安装平面是否与机台平行都有关系。
