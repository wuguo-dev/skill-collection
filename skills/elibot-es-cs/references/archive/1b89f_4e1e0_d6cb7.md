# CS力传感器修改空载标定点位

URL: https://docs.elibot.cn/cs/1b89f/4e1e0/d6cb7
发布时间: 2026-06-05

# 1. 简介



客户现场设备安装过程中，若力控传感器转接板安装长度过长，会导致力传感器空载标定作业时出现点位干涉问题，无法完成正常标定，本文档详细说明通过SSH远程登录设备系统，修改力传感器空载标定点位的完整操作流程，解决标定点位干涉问题，保障传感器空载标定作业正常进行，适用于现场设备调试、维护人员操作使用



# 2. 操作流程



## 2.1网络环境准备



使用网线将PC端与控制柜FB1网口物理连接，手动设置PC端IP地址与控制柜FB1网口IP地址为同一局域网网段，确保网络互通，无IP冲突。



## 2.2远程SSH登录系统设备



打开PC端已安装的终端工具（比如widows下的git bash），根据设备控制柜型号输入对应登录指令，完成远程登录



1. A9控制柜登录指令：ssh root@FB1 IP -p1022



2. D9控制柜登录指令：ssh root@FB1 IP



3. 设备统一登录密码：elibot



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_931407_icCVvafEP_M8J8gX_1767169791?w=964&h=741&type=image/png)



## 2.3定位文件目录



1.A9控制柜成功登录设备系统后，进入rbctrl文件夹，在该目录下检索找到eli_resource文件夹，进入对应目录,如下图所示：



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_217261_x0bvgiu6P2WckNKy_1767170354?w=740&h=449&type=image/png)



2.D9控制柜成功登录设备系统后，进入rbctrl文件夹，在该文件夹打开RT_CONTROLLER文件夹，同时检索找到eli_resource文件夹，进入对应目录,如下图所示：



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_469837_nuGwpI3DmJWlbGt__1780642534?w=1140&h=704&type=image/png)



## 2.4修改力控点位



1. 输入Vi编辑指令，启动文件编辑功能；打开空载标定文件ft_sensor_calibration.script



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_378369_srB8GiqZVvYJu3WJ_1767170945?w=801&h=444&type=image/png)



2. 按下键盘i键，进入文本插入编辑模式；



3. 参照现场设备实际工况，修改文件内对应的空载标定点位参数，操作方式与普通文本编辑器一致



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_97245_DdIFDfQhQyfhWjpg_1767171043?w=1280&h=1009&type=image/png)



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_963461_-il-6dePYRjXIl54_1767171451?w=1280&h=1004&type=image/png)



4. 参数修改完成后，按下ESC键，退出插入编辑模式，返回系统普通指令模式；



5. 输入英文指令 :wq（英文冒号开头），按下回车键确认；



6. 指令说明：w代表文件保存（write），q代表退出编辑器（quit），执行指令后自动保存修改内容并退出编辑界面



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_618840_5sw9zOrG2jUapyWQ_1767171705?w=1285&h=1006&type=image/png)



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_49142_yKNKxoAX6zSrsdvQ_1767171850?w=1123&h=474&type=image/png)



# 3. 注意事项



修改文件点位后空载标定时如果显示传感器标定任务未启动，可以检查下文件中的格式比如换行、逗号、空格等是否与原始文件一致，修正异常格式后重新保存即可。
