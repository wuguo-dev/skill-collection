# 1、简介



CS机器人示教器软件界面下方内置有文件管理器功能，该功能可以管理程序文件、配置（全局变量）文件和脚本等内部文件，以及可以管理外部存储介质U盘文件；



文件管理器可以进行单个程序的复制删除等操作，与外部存储介质U盘的单个文件或者文件夹进行相互传输；



连接u盘后，可以将机器人内部单个程序、配置文件选择保存至u盘或者将u盘内单个程序、配置文件传输至机器人，操作步骤如2.2.2



### 1.1 文件类型说明



CS机器人文件后缀类型分别有：



1、 .elico是机器人的功能插件文件，



2、 .script是机器人任务能导入使用的脚本文件



3、 .task是机器人任务程序文件



4、 .old是程序文件修改后生成的备份文件



5、 .configuration是机器人配置文件，



6、 .configuration.variables是机器人全局变量文件
