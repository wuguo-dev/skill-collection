# 1. 简介



E6S100 报警所指示的是：安全系统报警，机器人处于安全违规状态。其具体释义如下：



1. E代表：大的报警类别范畴。



2. S代表：内部的小类别。



3. 6代表：安全系统报警。



故障原因：安全IO输入状态高低电平不一致;

# 2. 排查及处理方式



## 2.1 安全IO输入状态是否一致排查



1、 排查安全 IO(急停和防护停止)输入状态高低电平是否一致，急停和和防护停止是双回路，两个回路必须同时使用并保证输入状态高低电平一致，双回路可确保在发生单一故障时不会丧失安全功能。



如下图所示B1中的EI0和EI1为急停双回路，必须保证EI0 EI1输入状态高低电平一致；SI0和SI1为防护停止双回路必须保证SI0 SI1输入状态高低电平一致。

## 2.2 可配置IO输入状态是否一致排查



可配置IO是可以当作安全IO来使用的(需要配置)，安全IO都是双回路，必须保证两个回路输入状态高低电平一致，否则会报安全违规。



1、 检查可配置IO是否配置成了安全IO。



如下图所示，CI0和CI1已配置成了安全IO(防护重置)，所以必须保证CI0和CI1输入状态一致。



如果可配置IO未配置成安全IO就不用往下继续排查！

# 3. 常见问题解答



1、 所有安全型 IO 均具备冗余性（两个独立通道）。保持两个通道独立，可确保在发生单一故障时不会丧失安全功能，并且该IO输入对状态持续超过80ms(在2.13.2版本后)高低电平不一致机器人会报警；



2、 可配置IO配置成安全IO需要安全密码，安全密码可在设置里面自行设置；
