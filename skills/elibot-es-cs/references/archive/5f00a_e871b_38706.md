# 机器人应用升级失败

URL: https://docs.elibot.cn/cs/5f00a/e871b/38706
发布时间: 2026-01-13

# 1. 简介



本文将介绍应用升级失败的处理方法。



需要注意，更新应用所需要的U盘格式要为fat32，其他的格式的U盘有可能会导致更新失败。



# 2. 操作流程



## 2.1. 不可用的更新文件。

如 图1 所示，出现 "不可用的更新文件" 的提示时，一般是更新文件损坏了，需要重新拷入更新文件到U盘。



重新拷入更新文件后，如 图2 所示，检查一下更新文件大小，如果显示是0kb，说明更新文件是损坏的。



U盘拔出时要注意，不要直接拔出，将U盘弹出后再拔出，防止更新文件损坏。

## 2.2. 升级过程中，报 "控制软件 升级失败" 。



![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ0ODMwLCJwYXRoIjoiMjAyNjAxMTUtMjc2OTQzNC1xbDRsdTgiLCJ0aW1lc3RhbXAiOiIyMDI2LTAxLTE1VDE1OjAyOjI1LjY5MiswODowMCIsInRva2VuIjoiIn0sImV4cCI6IjIwMjYtMDgtMDlUMTU6NTk6NTkuOTk5WiIsInB1ciI6Im9yZ2FuaXphdGlvbl83OG5jejN6LS1tYWluLXZlcnNpb24ifX0--6518a36addd9a811f9f1bcd4713b2ea781cf6d58a1c0fd0d5f3e0bb9608ff3da/20260115-2769434-ql4lu8)



图3



如 图3 所示，出现 "控制软件 升级失败" 的提示时，大概率是更新文件损坏了，重新拷入更新文件到U盘即可。



重新拷入更新文件后，还是会出 "控制软件 升级失败" 的提示，那就是U盘损坏了，重新更换一个U盘。



## 2.3. 识别不到更新文件。 ![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ0ODI5LCJwYXRoIjoiMjAyNjAxMTUtMjc2OTQzNC0zYjFhZGEiLCJ0aW1lc3RhbXAiOiIyMDI2LTAxLTE1VDE1OjAyOjI1LjI2OCswODowMCIsInRva2VuIjoiIn0sImV4cCI6IjIwMjYtMDgtMDlUMTU6NTk6NTkuOTk5WiIsInB1ciI6Im9yZ2FuaXphdGlvbl83OG5jejN6LS1tYWluLXZlcnNpb24ifX0--c58110feda698b68d067c847290c097257b83cdb23333454909554cb97e6e346/20260115-2769434-3b1ada)



图4



如 图4 所示，正常点击搜索后，会出现红色箭头所指的更新文件。



如果没有，将U盘插到 控制柜 上的usb接口，再点击搜索。如果还是搜索不出更新文件，



那就是更新文件后缀不对、U盘损坏了、U盘格式不是fat32。如果可以搜索出更新文件，那就是 示教器 上的usb口损坏了。
