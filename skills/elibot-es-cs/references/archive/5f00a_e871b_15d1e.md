# 机器人不运动排查方法

URL: https://docs.elibot.cn/cs/5f00a/e871b/15d1e
发布时间: 2026-01-13

# 1. 简介



机器人不动作的情况用于排查原因。



# 2. 操作流程



## 1. 查看左上角运行状态。



![](https://wdcdn.qpic.cn/MTY4ODg1NjU4NjUwNTY0MA_641977_IiVJ48ET1thvhg8n_1742197211?w=1282&h=802&type=image/png)



1. 可以先根据颜色确认机器人是正常状态（绿色；正常状态，黄色；未释放抱闸/保护性停止，红色；报警/“关闭电源“状态）



需要确保机器人是处于”绿色状态“。



![](https://wdcdn.qpic.cn/MTY4ODg1NjU4NjUwNTY0MA_563237_RlYWgGWTjZ4tRwVI_1742190911?w=204&h=66&type=image/png)![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ0NjM0LCJwYXRoIjoiMjAyNjAxMTUtMjc0MzMxOS1iamtpNGMiLCJ0aW1lc3RhbXAiOiIyMDI2LTAxLTE1VDE0OjMzOjA3LjE4MyswODowMCIsInRva2VuIjoiIn0sImV4cCI6IjIwMjYtMDgtMDlUMTU6NTk6NTkuOTk5WiIsInB1ciI6Im9yZ2FuaXphdGlvbl83OG5jejN6LS1tYWluLXZlcnNpb24ifX0--61bf0073f1d32b942fe2faade42415f72a25d9c8ea1a626e4b2de73b16ed7125/20260115-2743319-bjki4c)



![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ0NjQwLCJwYXRoIjoiMjAyNjAxMTUtMjc0MzMxOS1tdG1hNnkiLCJ0aW1lc3RhbXAiOiIyMDI2LTAxLTE1VDE0OjMzOjA3LjUwOCswODowMCIsInRva2VuIjoiIn0sImV4cCI6IjIwMjYtMDgtMDlUMTU6NTk6NTkuOTk5WiIsInB1ciI6Im9yZ2FuaXphdGlvbl83OG5jejN6LS1tYWluLXZlcnNpb24ifX0--2874c429f70bd46f3bfd9b5e0b4d5563e3859dc5f045fd5153820b20aac127df/20260115-2743319-mtma6y)



2.运行模式，如果是正常模式则需要让任务运行（左上角处于“运行中“），则机器人才会根据任务来执行需要动作。



## 2. 查看程序指针。



![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ0NjM2LCJwYXRoIjoiMjAyNjAxMTUtMzQ1MDIxNi1yenlob3kiLCJ0aW1lc3RhbXAiOiIyMDI2LTAxLTE1VDE0OjMzOjA3LjMyNyswODowMCIsInRva2VuIjoiIn0sImV4cCI6IjIwMjYtMDgtMDlUMTU6NTk6NTkuOTk5WiIsInB1ciI6Im9yZ2FuaXphdGlvbl83OG5jejN6LS1tYWluLXZlcnNpb24ifX0--3ef6a5a7562d4c4ac45698ea9ca91ed997c017c643f557e18da3b56070fa1312/20260115-3450216-rzyhoy)



在处于任务运行中的时候机器人如果没有任何动作也无报警可以查看对应任务的程序指针，通过指针查看当前程序执行在哪一行（比如以上程序目前是在处于等待指令行），由此来判断不动作的原因。位置1是程序指针，如果找不到位置1的程序指针，可以点击位置2，该位置是表示跟踪到程序指针位置1。



## 3. 查看是否添加断点



![](/cs/-/dam/assets/organization_78ncz3z--main-version/eyJfcmFpbHMiOnsiZGF0YSI6eyJpZCI6MjQ0NjQyLCJwYXRoIjoiMjAyNjAxMTUtMzI5NDk3Ny1sbHpvZzkiLCJ0aW1lc3RhbXAiOiIyMDI2LTAxLTE1VDE0OjMzOjA3LjYwNCswODowMCIsInRva2VuIjoiIn0sImV4cCI6IjIwMjYtMDgtMDlUMTU6NTk6NTkuOTk5WiIsInB1ciI6Im9yZ2FuaXphdGlvbl83OG5jejN6LS1tYWluLXZlcnNpb24ifX0--068d4f3d4b324f2a4af5f6331bc65007c2929e94a378ba52285be0928e698b4e/20260115-3294977-llzog9)



如果不小心添加添加了断点，则可以在点击一下断点图片位置把断点取消叫就可以运行了。
