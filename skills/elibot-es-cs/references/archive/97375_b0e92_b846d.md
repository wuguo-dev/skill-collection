# 远程无线控制机器人

URL: https://docs.elibot.cn/cs/97375/b0e92/b846d
发布时间: 2026-01-15

# 1、简介



在AGV小车上或者一些特定场景下示教器线缆长度无法满足需求时，可以外接一个路由器 将有线网络转化为无需网络，再通过电脑连接这个网络来达到控制机器人的目的。

答：首先可以进行PING 一下，看看网络是否处于连接状态，若网络正常可检测机器人网口是不是FB1网口
