# 1. 简介



本文主要介绍CS机器人的4种模式以及功能介绍，混合模式，本地模式以及远程模式，本地模式又分为手动模式以及自动模式.



# 2. 模式介绍及说明



模式名称功能备注混合模式（默认模式）包含下方所有模式功能出厂默认手动模式移动机器人，监控信号，编写，修改运行程序设置--密码--模式--添加自动模式移动机器人，监控信号，运行程序设置--密码--模式--添加切换为手动模式需输入密码 本地模式通过示教器控制机器人禁止外部端口控制机器人，例如30001，I/O和Dashboard等 远程模式通过外部源控制机器人例如30001，I/O和Dashboard等
