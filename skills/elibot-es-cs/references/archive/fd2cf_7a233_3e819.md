# SFTP文件传输（notepad++）

URL: https://docs.elibot.cn/cs/fd2cf/7a233/3e819
发布时间: 2026-01-15

# 1.简介



用户可通过 SFTP 方式，将 Python 脚本程序及各类配置文件上传至机器人控制器，同时支持从机器人控制器下载相关文件，实现远程文件传输与程序管理。



# 2.操作流程



## 2.1. notepad++软件下载



下载地址：Download Notepad++ - free - latest versionSFTP：List



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_555513_pMVbPpFsI75XB7jy_1741145746?w=756&h=359&type=image/png)



## 2.2. notepad++SFTP 插件安装



插件安装：打开软件>任务栏插件>插件管理>搜索 SFTP>选择 NppFTP 安装



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_270100_edo4BLKH4kxdL1M9_1741145758?w=756&h=499&type=image/png)



## 2.3. 与机器人建立连接



1.机器人与 PC 通过网线连接（机器人连接接口为 FB1 口，通过交换机中转也可以实现）



（FB1 网络显示网络已连接则表示连上,应注意 IP 网段和电脑对应网段应保持一致）



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_426269_8rrVlmeRGYGfDMKs_1741145767?w=615&h=333&type=image/png)



2.打开notpad++连接窗口



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_877766_dRp-cUrecFXaP27z_1741145777?w=574&h=362&type=image/png)



3. 选择“配置文件设置”。



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_993380_0p5bdmdAh4WQX1oK_1741145790?w=443&h=284&type=image/png)



4.添加新配置文件。



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_873524_dru8i0jmXsDdIzDj_1741145798?w=556&h=360&type=image/png)



5.设置连接信息。



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_466467_X8-6EmAcIqxf8dD2_1741145809?w=695&h=573&type=image/png)



6. 然后单击连接



![](https://wdcdn.qpic.cn/MTY4ODg1NjY2NzcyMjMwNA_457269_zMQ5J9i_A5VCgXfN_1741145822?w=438&h=359&type=image/png)
