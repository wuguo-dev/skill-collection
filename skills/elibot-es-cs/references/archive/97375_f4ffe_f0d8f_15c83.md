# 应用升级（U盘）

URL: https://docs.elibot.cn/cs/97375/f4ffe/f0d8f/15c83
发布时间: 2026-04-03

# **1. 简介**



在客户现场是，如果需要一些新功能，或者优化下系统bug，可以通过升级应用解决。



1.1 艾利特升级软件包.eup文件，可以在官网下载或向艾利特工程师索取。



1.2 U盘一个（格式最好是FAT32,再次NTFS）



官网应用下载链接：[下载中心_机器人技术-艾利特机器人](https://www.elibot.com/service/technical?kw=&type1=9&type2=&type3=&type4=&type5=34&wd=1&tp=1)
