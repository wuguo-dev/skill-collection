# 快速修改点位

URL: https://docs.elibot.cn/cs/d9b09/58928
Published: 发布时间: 2026-01-15

# 1. 简介



本文档详解 CS 系统点位快速修改方法，提供高效操作流程与实用技巧，助力工程师快速完成点位调整，提升现场调试效率。



# 2. 操作流程



（1）如果这个点位坐标经常用到（如：home点位）在需要从另一个点位回home点位时不需要新建一个路点，程序中可以选中已保存的home点，复制粘贴到需要的位置，在后续需要更新home点位/名称时只需要跟新一个home点坐标，其他home点坐标/名称都会同一修改（关联性）。



选择复制的点位——点击复制——点击粘贴位置——点击粘贴



![](https://wdcdn.qpic.cn/MTY4ODg1NzczNDQyNjQyMA_482656_pCK9BXXeF5FevnGM_1755002063?w=1179&h=756&type=image/jpeg)



（2）：如果大批量点位修改，但知道修改的方向如：路点2 Z需要抬高10mm



![](https://wdcdn.qpic.cn/MTY4ODg1NzczNDQyNjQyMA_151224_OznJ8wlKxBgiU_Wg_1755002659?w=1179&h=702&type=image/jpeg)



选中需要修改的点位——点击编辑位姿



![](https://wdcdn.qpic.cn/MTY4ODg1NzczNDQyNjQyMA_834016_nR7FVGZ9NNTSwqvN_1755002717?w=1179&h=738&type=image/jpeg)



找到Z的坐标箭头 左箭头是减去多少mm 右箭头是加多少mm（以z方向抬高10mm举例）



![](https://wdcdn.qpic.cn/MTY4ODg1NzczNDQyNjQyMA_979393_8v5BjCzKndhA13Aq_1755002847?w=1187&h=745&type=image/jpeg)



点击右箭头——输入10——点击回车（对应数值会实时修改）——点击确认——路点2 Z方向抬高10mm修改完成。

点击配置——全局变量——点击修改的位置变量——编辑



![](https://wdcdn.qpic.cn/MTY4ODg1NzczNDQyNjQyMA_708109_WWx4ZkDUUxCxAz5P_1755003956?w=1179&h=738&type=image/jpeg)



[0,0,0,0,0,0]第一0代表X



第二0代表Y



第三0代表Z



第四0代表RX



第五0代表RY



第六0代表RZ



这里显示的数值单位是m（米）找到Z:1.07点击叉修改为1.08——点击回车——点击确认——修改完成



# 3. 常见问题解答



如果可变位置变动比较大建议直接删除变量，直接保存新的当前位姿 修改为之前的名称
