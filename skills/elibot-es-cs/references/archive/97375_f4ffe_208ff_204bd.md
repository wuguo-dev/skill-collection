# 备份与恢复（U盘）

URL: https://docs.elibot.cn/cs/97375/f4ffe/208ff/204bd
发布时间: 2026-02-11

# **1. 简介**



本文档主要介绍U盘备份导入法，U盘格式建议FAT32(其次NTFS)**。**



### **1.1 注意事项:**



1.1.1 备份功能导出的主要文件为机器人程序、配置文件（同型号可通用）以及当前机器人零位、DH参数（不通用）；



1.1.2备份恢复功能尽量选择同一型号机器人或应用环境类似的机器人；



1.1.3 恢复备份文件时不勾选【恢复机器人零位、DH标定等数据】、【恢复本体全部数据】，该数据每台机器人不通用，勾选后恢复会影响实际运行，该功能仅用于换机；



### **1.2 主要用途：**



1.2.1 ：用户可将任务和配置文件备份到 U 盘，以免发生意外删除程序配置等情况；



1.2.2：也可以备份后导入其他机器人，使用相同的任务和配置，快速复制至其他应用项目；

# **3. 常见问题解答**



3.1：插入U盘后备份恢复时显示未查找到USB设备，检查U盘是否不支持，更换新的U盘，或者插入其他机器人查看是否可以，更换新U盘后依旧查找不到，请联系艾利特技术人员。



3.2：进入U盘后如需要打开文件夹，快速双击文件夹即可打开。



3.3：只进行程序复制备份恢复情况下，不勾选恢复机器人零位、DH标定等数据、不勾选恢复本体全部数据，该数据每台机器人不通用，勾选后恢复会影响实际运行。



3.4：备份恢复文件不完整时，联系艾利特售后人员解决。



3.5：备份失败时，检查机器人本地文件是否存在大文件，如果有建议清理。



3.6：机器人系统2.15极其以上的系统版本，更新本体数据时，需输入安全密码，附安全密码连接.



[缩减模式，安全平面及软限位](https://docs.elibot.cn/cs/97375/b0e92/eb9e8)



3.7：需单个恢复文件时，参考文档单个文件传输。



[单个文件传输](https://docs.elibot.cn/cs/97375/f4ffe/39102)
