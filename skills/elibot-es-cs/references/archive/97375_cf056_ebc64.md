# 自由拖动与手动移动机器人

URL: https://docs.elibot.cn/cs/97375/cf056/ebc64
发布时间: 2026-02-11

# 1. 简介



CS机器人如何使用自由拖动功能。



# 2. 操作流程



打开自由拖动首先保证机器人在未运行状态，无报警状态，处于正常模式，安装方式，末端负载重心设置正确。



## 2.1、示教器拖动按钮触发



编号3为示教器背部的拖动按钮，持续按压此按钮，使机器人本体进入并保持拖动示教模式。松开按钮，机器人本体 退出此模式。

## 2.2、示教器屏幕上拖动功能按钮触发



在示教器上操作界面，点击自由拖动按钮，就能实现打开机器人拖动模式

## 2.3、机器人本体末端拖动按钮触发



机器人末端法兰有两个按钮，这两个按钮都是拖动按钮，只需其中一个长按按钮，机器人进入自由拖动状态。在此模式下，用户可自由拖动机器人至期望点位。 松开按钮，机器人立即退出自由拖动状态。

## 2.4、外部输入按钮触发拖动



在机器人配置中，设置IO的输入数字信号，触发动作为拖动模式，然后保存配置。此时当设置的信号被触发时，机器人就会进入拖动模式。
