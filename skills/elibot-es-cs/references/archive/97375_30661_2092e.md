# 1.基座坐标系简介



## 1.1 基座坐标系定义



CS/ES机器人的全局参考坐标系，其零点固定在机器人底座安装位置。



## 1.2 基座标系方向

# 2. 基座坐标系的特点



## 2.1 坐标系位置固定，与机器人本体绑定。



2.2 不随工具、工件或外部设备变化。



2.3 是机器人内部运动计算的基础参考系。



# 3.注意事项：



如果机器人发生剧烈撞击，可能会导致机器人零点丢失；这时基座坐标系会（偏移/不准确)，需要返厂重新标定。
