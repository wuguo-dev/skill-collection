# 本机TCPIP软件与虚拟机连接

URL: https://docs.elibot.cn/cs/fd2cf/0ab86/926f2
发布时间: 2026-01-15

# 1. 简介



本文将介绍，如何使用本机 TCPIP 测试软件与 CS 虚拟机建立连接。



# 2. 操作流程



本文示例的 TCPIP 测试软件：SocketTool



机器人软件版本：V 2.12.0



用户手册下载地址：技术资料_机器人技术-艾利特机器人



脚本手册下载地址：技术资料_机器人技术-艾利特机器人



## 2.1. 找到在本机运行的虚拟机s软件的IP



Win键 + R 输入 cmd ，打开 cmd 窗口。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_63948_CCNBjfO4NqbSxF5k_1720766689?w=620&h=314&type=image/png)

cmd 窗口输入 ipconfig ，找到虚拟机软件的 IP：192.168.15.123



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_556037_fznA_Gv_7CakMCiT_1720767143?w=660&h=198&type=image/png)



## 2.2. 找到在虚拟机运行的系统的IP



右击鼠标，点击在终端打开，打开在虚拟机中执行的系统的终端。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_316060_db4zvekkA751c8mn_1720767379?w=212&h=201&type=image/png)
 在终端输入 ifconfig ，找到 IP ：192.168.15.128 。![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_206421_-euequmUHIhhivAu_1720767674?w=725&h=423&type=image/png)



## 2.3. 本机做主站，SocketTool操作



本机做主站，机器人做从站。在 SocketTool 软件里，创建客户端，输入在 2.2 里获取的IP：192.168.15.128 ，端口号参考用户手册里的二次开发端口。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_191345_ym6bDSswOxisdpCc_1720768049?w=1052&h=792&type=image/png)



以 30001 端口为例，连接成功后，即可收机器人的反馈。本机做主站，机器人做从站，机器人不需要做任何操作。![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_805935_I0BhcgEDwhssAerJ_1720768704?w=1052&h=797&type=image/png)



## 2.4. 本机做从站，机器人操作与SocketTool操作



参考 CS脚本手册 ，写一个简易的通讯脚本，IP 输入目录 2.1 里获取的 IP：192.168.15.123 。



```
ret = socket_open("192.168.15.123",6000)
while ret == False:
  textmsg(ret)
  ret = socket_open("192.168.15.123",6000)
  sleep(0.5)
textmsg(ret)
socket_send_string("hello")

```



本机 SocketTool ,创建一个服务器，端口6000。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_568311_LCFviowagJZM89Jt_1720770077?w=1053&h=803&type=image/png)
机器人运行程序，连接成功，机器人会在运行窗口，打印 True 。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_131995_Zv-Pf3fTezmHNwz4_1720770187?w=1277&h=822&type=image/png)
本机这边，SocketTool 会收到机器人发过来的字符串。



![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_663511_NtN6XOxchAITJfCI_1720770283?w=1056&h=803&type=image/png)



# 3. 常见问题解答



3.1在虚拟机内的机器人软件，不需要设置 IP 地址。与本机通讯，使用 2.2 目录获取的 IP，可以当作是机器人的 IP 。![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_195230_4QH59EQ9UtDWNQK__1720770626?w=1274&h=824&type=image/png)



3.2.目录 2.1 里获取的 IP 是虚拟机软件，虚拟网口的 IP ，可以当作是本机的 IP 。![](https://wdcdn.qpic.cn/MTY4ODg1Nzg4NTQ3OTUzMQ_499820_9t_fk3Es2ygAaH9k_1720771158?w=791&h=272&type=image/png)
