## SDK 仓库（GitHub：Elite-Robots）
- **Python**：`Elite_Robots_CS_SDK_Python`（基于 pybind11 + CMake，为 C++ SDK 提供 Python 绑定）。
  - Requirements：CS Controller 2.13.x ≥ **2.13.4**，2.14.x ≥ **2.14.2**；python3 ≥ 3.6。
  - 编译安装见仓库 BuildGuide（编译安装向导）；API 手册见仓库 doc。
- **C++**：`Elite_Robots_CS_SDK`。
- **C#**：`Elite_Robots_CS_SDK_CSharp`（gitee.com/elibot_dukang/Elite_Robots_CS_SDK_CSharp）。
- 其它语言：暂未提供 SDK 的用端口通信方式操作（见 06 通讯端口）。

## 二次开发启动流程（SDK 一键启动）
保持机器人为**远程模式**，用 29999 端口：
1. 建立 socket 连接（ip, 29999）。
2. `robotControl -on` → 返回 `Powering on` = 上电成功。
3. `brakeRelease` → 返回 `Brake is released` = 抱闸释放成功（循环直到成功）。
4. `play` → 返回 `Starting task` = 任务启动。
5. `task -r` → 返回 `Task is running` = 任务运行中。
- 代码模板（connectETController / dashboard_shell 函数）见官方「二次开发启动流程」。
