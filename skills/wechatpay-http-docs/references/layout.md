# 排版规范

## 视觉参数

以白底、绿色强调、浅灰参数表和代码块建立层级。以下为可直接用于重现本技能风格的默认参数，用户提供品牌规范时按其要求调整。

| 元素 | 默认参数 |
| --- | --- |
| 主强调色 | `#07A36B` |
| 正文字色 | `#202A35` |
| 辅助文字 | `#697586` |
| 表格分隔线 | `#E2E7EC` |
| 代码及表头背景 | `#F5F7F9` |
| 方法路径栏背景 | `#F0F8F4` |
| PDF 纸张 | A4 纵向 |
| PDF 页边距 | 左右 48 pt，上 52 pt，下 56 pt |
| 文档及接口主标题 | 21 pt，行距约 29 pt，粗体 |
| 章节标题 | 11.5 pt，行距约 18 pt，段前 10 pt，段后 5 pt |
| 正文 | 9 pt，行距约 13.2 pt |
| 表格文字 | 8–9 pt，行距约 11.5 pt |
| 代码 | 等宽 8.7–9 pt，行距约 12 pt |

中文选用环境中存在且支持嵌入的字体，英文代码选用等宽字体。Windows 可检查微软雅黑与 Consolas，其他环境发现可用的中文及等宽字体并验证字形。字体路径通过环境发现或作者脚本参数传入。

## 标题与方法路径栏

- 接口标题之后放用途短句与方法路径栏，之后进入参数及示例。
- 方法使用醒目色块，路径使用等宽字体。默认栏高约 42 pt，方法标签约 44 × 21 pt。
- 路径栏与后续内容保持衔接。长路径自然换行或增加栏高，保持可读字号。
- 接口跨页时，在页眉保留接口名称及方法路径作为定位信息。

## 参数表

- 使用浅灰表头与细横线，单元格内边距约 4.5 pt。跨页重复表头。
- 请求表优先保证名称与说明列宽，可采用页面正文宽度的 23%、12%、9%、11%、45%。
- 应答表可采用字段路径 36%、类型 18%、返回条件 14%、说明 32%。按实际字段长度调整。
- 字段路径使用等宽字体，中文说明使用正文字体。完整对象路径可换行，保持可复制的原字段名称。
- 父子字段以点路径、缩进或轻量字重表现。以文字表达必填条件和枚举含义，颜色承担辅助作用。
- 对较长说明允许合理跨页。保持字段名与其说明的关联，避免整张长表被强制放在同一页。

## 示例代码

- 使用浅灰背景、足够留白、双空格缩进。中文字符串有可用字形。
- JSON 可采用字符串绿色、布尔和 null 蓝色的轻量语法着色。HTTP 报文与 JSON 内容分别标识。
- 长 JSON 在属性边界、对象层级处换行，通过标准解析器验证后再排版。长字符串按视觉软换行处理，保持复制出的值完整。
- 较长示例可跨页，在续页保留示例名称或接口定位信息。代码块拆分后仍应保证逐行可读。
- 保持代码可选择和复制，交付前检查长行宽度及代码块边界。

## 目录与分页

- 正文前提供接口目录，PDF 目录项链接到接口起始页，各接口加入书签。
- 页脚提供页码和返回目录链接。总页数、目录页码与书签目的地依据最终版面生成。
- 接口数量较多时可在新页开始各接口。短接口是否同页按内容密度决定。用户已指定某接口的页数或分页方式时遵循其要求。
- 标题与后续首段或首行表格保持同页。避免单独的尾部注释页、单行代码续页、表头孤页。
- 采用 ReportLab 时，可使用首次构建收集接口页码、第二次构建写入目录的方式。两次的接口页码映射应一致。书签注册发生在接口标题实际布局完成时，避免延迟保存页面导致链接目的地错位。
- 网页采用目录导航与锚点，适配窄屏参数表和代码横向滚动。导出 PDF 时另外检查打印样式。

## 输出检查

1. 提取最终文件文本，对照源文档检查接口、字段及业务约束完整性。文本抽取的空白差异可规范化，字段内容保持原值。
2. 渲染 PDF 每一页，逐页查看或通过清晰的分组总览检查版面。密集参数表、长代码块、跨页边界另看足够分辨率的单页。
3. 检查中文缺字、裁切、重叠、表格越界、失去关联的字段和分页留白。通过回流内容修正分页。
4. 检查目录每个链接、接口书签和返回目录链接的目标，核对可见页码与总页数。目录页数变化后重新执行。
5. 发布前重读目标文件的状态，存在并发修改时合并本次内容。只覆盖用户指定的文件，检查发布后的字节或哈希与已验证成品一致。

检查用的中间 PDF、页面图片和作者脚本放在任务临时目录。按用户需要交付成品及可编辑源文件。
