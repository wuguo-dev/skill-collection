# 排查与验证

先保存脱敏错误类别、版本与调用方式，再定位阶段，不输出整份凭据或请求/状态。

| 现象 | 优先检查 | 验证 |
| --- | --- | --- |
| 缺类/缺方法/自动配置失败 | 三类 BOM、有效依赖树、Boot、模型 Bean | 隔离编译和启动，定位冲突来源 |
| 模型 401/403/地域或模型错误 | Key 注入、端点、账号权限、模型 ID | 最小无工具请求区分配置故障 |
| 不调用工具 | 模型能力、callback 注册、schema/description | 受控模型输出指定调用，检查执行 |
| 工具身份缺失 | helper/常量版本、上下文注入 | 缺身份拒绝，可信身份到达用例 |
| 串会话/不记忆 | saver 实例、threadId、归属、并发 | 两身份两线程隔离及重启恢复 |
| JSON 解析失败 | 提供商支持、schema、真实返回类型 | 正常/缺字段/畸形输出与有限重试 |
| 无界工具循环 | 调用限制、超时、重复可重试错误 | 达预算停止并释放资源 |
| 流文本重复 | 增量/完成事件重复追加、事件映射 | 最终全文一次、取消与错误传播 |
| HITL 无法恢复 | 名称、hook/saver/threadId、反馈 ID/name/result | 批准/编辑/拒绝、缺项中断、会话越权 |
| RAG 无证据/越权召回 | 过滤位置、索引和 embedding、阈值 | 空结果、有效来源与跨资源拒绝 |
| Skills 能发现不能读取 | 路径、覆盖、read_skill/执行工具 | 允许目录可读，未授权命令不执行 |

对应细节见 [版本](01-setup.md)、[工具](02-agent-tools.md)、[记忆/扩展](03-memory-output-hooks.md)、[流式/审批](04-graph-stream-hitl.md)、[组合](05-composition.md) 与 [官方来源](00-sources.md)。权限、幂等和取消验证是本技能的工程建议，不冒充框架自动保证。

## 分层验证

1. 静态/编译：实际构建命令、依赖、包名/签名；源码核对不等于编译通过。
2. 确定性：假的 ChatModel、受控工具、隔离存储；检查参数、顺序、次数、失败与权限。
3. 集成：当前任务涉及持久化/审批/流式时，测重启、恢复、取消和幂等，使用隔离资源。
4. 真实模型：有授权和凭据时少量非敏感输入，说明模型、版本及范围；避免可变文案逐字断言。

交付区分文档核对、编译、受控测试和真实调用。缺网络/凭据或版本冲突时说明未验证项，不伪造成功响应。
